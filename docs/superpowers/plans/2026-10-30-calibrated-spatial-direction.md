# 软方向标定实验实施计划

> 使用 executing-plans 在当前仓库执行，先写失败测试，再实施与验证；完成后独立审查、提交并推送。

**目标：** 收益评估网络从随机权重训练 200 个窗口，检验数值一致的软方向监督能否改善后期共同价值退化。

**设计依据：** 用户批准软方向方案，并要求从头训练 200 个窗口、只跑新版，沿用上一轮作为对照。

**架构：** 继续使用 SpatialBenefitNetwork、SpatialWindow、SpatialReplay。旧入口保留硬方向监督；新增独立实验族，仅替换方向监督。给 SpatialLearner 添加可覆盖的方向损失接口，避免复制训练流程。

**技术：** PyTorch，现有精确局部渲染教师与批量空间 token 网络。

## 固定配置

- 冻结已有编解码器；收益评估网络、optimizer、replay 和概率表全新初始化。
- 200 个窗口，前 50 个拟合尺度，随后每窗口 64 次网络更新、每批 8 组；共 9600 次网络更新。
- 真实标签预算 64 组／窗口，验证容量 512，replay 容量 8192。
- Truck，10 dB，0/8/24/48，β=0.1，MSE＋SSIM，绝对／共同／档间差值损失不变。
- 本轮仅启动预训练，概率表不更新；单独输出目录。

## 损失定义

六对档位的真实 RD 差值归一化后为 a，预测差值为 e；包含解析通信成本，尺度为现有训练标签拟合的固定 rd 尺度。软目标为 sigmoid(-a)，预测 logit 为 -e。使用 Bernoulli KL，保留原有真实差值权重与 tie_fraction。实现为 BCE(predicted logit, soft target) 减去 BCE(true logit, soft target)，避免 log(0)。真实目标及权重停止梯度，浮点消减产生的微小负值截为 0。方向权重维持 0.25。

## 审查重点

1. 数值预测等于真实标签时方向梯度为 0。
2. 升／降档、q0 和通信成本均进入相同六对 RD 比较。
3. 极端差值、平局及 float32／float64 结果有限。
4. 旧实验损失、参数初始化与接口保持兼容。
5. 新实验不会载入旧收益网络，精确恢复仅接受同一实验族与方向目标。
