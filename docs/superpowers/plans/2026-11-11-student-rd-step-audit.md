# 学生 RD 单步诊断实施计划

按 executing-plans 与 test-driven-development 执行。用户已授权一次测验验证局部反馈、共享参数联动、硬判决、视角差异和教师约束衰减。

## 设计

独立入口读取学生运行的 latest（可指定 distilled）检查点与准备缓存，固定源编解码器。默认3个窗口，每个窗口都恢复同一学生权重与Adam状态，只推进窗口调度及随机噪声。第一窗口沿用检查点下一次训练的采样器、视角和噪声状态。各窗口互不续训。

沿用当前实际训练损失、逆纳入概率、32个真实纠偏与梯度裁剪。记录keep、positive、加权teacher的全参数及共享层梯度范数、夹角，记录各分支沿实际Adam参数步的内积。

在同一噪声下重解码并评估训练窗口及原校准视角：baseline、完整一步、0.1倍实际参数位移、只执行keep变化、只执行positive变化、仅执行已评价点的positive变化、仅执行未评价点的positive变化。完整一步与缩小一步同时比较固定反馈代理的变化及实际硬RD变化。完整损失使用原有教师衰减权重；若它已低于初始teacher_weight，增加恢复初始教师权重的一步对照，保留同一Adam状态与反馈。

各图复用同一次解码供两组视角评估，完全相同的档位图直接复用结果。费用使用ExactDeploymentCost，输出失真项和成本项，另外保存代理成本偏差。基线渲染必须复现梯度采集的source_distortion，配对噪声不符时停止。测试视角不参与本次检查。

输出逐视角结果、4x4转移矩阵、已评价/未评价点改变比例、边界间隔、预测与实测RD、keep/positive组合的非可加变化。报告只据实标记支持的疑点，避免将一次局部测试解释为最终泛化结论。
