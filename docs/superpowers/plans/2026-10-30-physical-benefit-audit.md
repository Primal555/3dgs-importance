# 物理特征收益评估收口审计实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 用一次离线审计确认采样口径、输入信息损失、固定池可拟合性和共同误差的影响。

**Architecture:** 读取现有 checkpoint 和其索引中的 replay。独立输出目录保存加权报告、固定池拟合轨迹与可复现的特征碰撞证明；生产训练入口保持当前行为。

**Tech Stack:** Python、PyTorch、NumPy、pytest、Bash。

**Spec:** 用户 2026-10-30 要求在修改前一次检查所有有依据的疑点；沿用前述固定 replay 检查设计。

## Global Constraints

- 当前工作树新增独立审计入口，保留已有未提交文件。
- 审计默认 CPU；不加载照片，不新增场景渲染或部署训练。
- 仅用训练记录选择固定池；验证记录只参与评估。
- 训练指标同时输出记录等权和原始采样重要性加权口径。
- 固定池拟合保持原损失、尺度、dropout、学习率及 AdamW 状态。
- 不从旧 checkpoint 推断精确历史访问次数；只报告此次实测固定池访问次数。
- 真实标签参与的 oracle 误差拆解仅作诊断。

## Review Focus

- 零权重、非有限值和源目录重叠必须明确拒绝。
- 原 replay 根路径为 Linux 时，支持在本地按相对索引读取。
- 固定池中保留高代价训练样本，同时标明它与自然样本分布不同。
- q0 平均保留指标和四动作最优选择分别计算。
- 同输入异标签的合成例子用独立整图渲染确认方向。
