# 候选区域输入与分离预测头实验计划

**目标：** 补充候选覆盖区域的背景信息，减少共同价值与档间差异在预测头上的耦合，同时保留普通样本精度。

**已授权范围：** 用户认可专业改进建议并要求尝试。本轮新增独立实验，不改在线分配行为。

## 设计

- 旧回放缺少候选足迹背景，服务器新采集默认 4096 条训练、512 条验证标签，使用冻结的多场景编解码器。
- 复用同源初始化器的 RD 参考、beta、相机划分、原始点索引及配对噪声。训练与验证按原 ResponseScheduler 的整块隔离。
- 旧的点级 tokens 保留；新增目标点及整个受影响块两个尺度的候选联合边界 9×9 规则采样。
- 每个档位输入背景目标 RGB、基线残差、候选的 alpha 加权 RGB／alpha、基线 alpha 和有效像素标志。候选 alpha 仅由已知投影参数计算，不使用干预图像或教师值。
- 两个尺度分别描述目标点和块内其他点变化。规则采样保留有限分辨率，未声称覆盖逐像素精确信息；精确渲染仍只用于教师标签。
- 新网络共享点编码器，独立共同价值头和档间差异头；正档输出为共同值加零均值差异。
- 两头均从旧 state_head 复制；新增区域分支以零投影接入，使两组初始预测一致。共享骨干仍保留耦合，不宣称完全消除梯度冲突。
- 原结构、新结构在同一份新标签上各进行 2000 次优化更新，损失均沿用有效的 CorrectionLearner，统一物理尺度。
- 全记录均匀洗牌循环，保留原采集重要性权重；本轮不增加困难采样或尾部损失。
- 每 250 次评价全部、普通、高差距样本的数值误差和选档代价；阈值只由训练标签拟合。
- 下载只保留轻量 review.tar.gz；新标签、初始化器及最终权重留在服务器。
