# 学生分配网络蒸馏训练与监测

目标：从随机初始化进行 1000 次全点蒸馏，每 100 次评价校准视角 RD，随后进行原有 1000 步 RD 学习。

方案：沿用当前学生网络、教师标签、编解码器、损失和数据划分。增加蒸馏中途校准与分档指标，保留原有结束时的测试评价。中途评价只使用校准视角；训练输出与原实验分开。

执行计划：

- [x] 添加分档指标和蒸馏中途校准的定向测试，验证当前实现缺失这些行为。
- [x] 实现每 100 次校准，确保中断恢复时校准事件与优化器状态一致；默认蒸馏预算改为 1000。
- [x] 运行学生网络相关测试，检查日志、脚本及提交差异。21 项通过，1 项因本地 CUDA 不可用跳过。
- [x] 完成只读独立审查，准备本轮提交及停止旧学生进程、从头启动的指令。交付分支为 experiment/feedforward-student。

验收：校准不使用测试视角；准确率区分四档最终动作和保留点内档位判断；从蒸馏中断恢复的参数与连续运行一致；源高斯与编解码器保持冻结。
