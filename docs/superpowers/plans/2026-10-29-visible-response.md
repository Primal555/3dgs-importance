# 可见贡献与独立监督尺度

范围：新增 `response_visible` 实验，保留当前加速版及其检查点。冻结编解码器，先进行 200 个窗口的评估器预训练，再显式启动分配。

## 输入

- 保留已有候选属性和局部图像特征。
- 每个训练视角将当前有效高斯按中心深度划为 12 层，用 4 次 RGB 渲染累计各层的实际 alpha 合成贡献。
- 层边界给出目标深度前透射率的上下界。q0 候选通过其正档位几何查询相同上下文。
- 新增整块候选相对 q0 的有符号 RGB 贡献变化、块区域图像与残差、目标点可见 alpha、区域尺寸，共 272 维。贡献使用固定基线遮挡上下文估计；完整换挡渲染继续提供监督标签。
- 输入在干预标签产生前固定；不读取验证标签或图像梯度。记录附加渲染次数和运行时间。

## 监督

继续输出统一的 q0 锚定价值。完整三档记录分别监督三档共同价值及中心化差值，换挡记录监督成对差值。各分量尺度仅由前 50 个窗口中的训练标签拟合。90% 绝对分位数设置独立尺度，并使用相对共同价值的数值下限处理近零分量。输出和通信代价保持原单位。

## 已有 replay 检查

CPU 工具读取旧实验检查点，统计共同价值、中心化差值、成对差值的分布与严重误判。可从同一网络、同一固定 replay、相同新 Adam 状态比较原损失与独立尺度损失。不修改源实验；不渲染、不更新概率表。

## 验证与交付

先验证监督梯度和透射率边界，再验证 q0、邻居响应、特征隔离和中断恢复；运行相邻模块定向测试。提交新增实验、说明和启动脚本，推送当前分支。新输入需要重新收集 200 个窗口，复用冻结的编解码器。

## 实施记录

- 已实现独立 family、949 维视角输入和三类监督尺度，旧 response 入口保持兼容。
- CPU 工具使用同一旧检查点、固定 replay、相同采样状态及全新 Adam，对比原损失和独立尺度损失。
- 初始测试因新模块未实现而失败；实现后，新增及相邻模块的 91 项定向测试通过，耗时 65.81 秒。
- 测试覆盖 q0、遮挡衰减、邻居颜色响应、干预标签隔离、原版本兼容、冻结检查、精确中断恢复与脚本 dry-run。
- 独立只读审查未发现阻塞问题，并额外验证了批量与逐块特征计算一致性。
- 未进行本地全场景渲染或全仓回归；实际 GPU 开销和画质收益由服务器实验测量。
