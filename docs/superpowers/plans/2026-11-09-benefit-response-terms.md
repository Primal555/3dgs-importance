# 收益网络交叉项与能量监督实验

用户批准：将 MSE 变化拆成真实交叉项 A 与非负变化能量 B，结构变化 S 独立保存，最终组合为旧单位下的 [A+B,S]。数值主任务保持固定系数，排序为有上界辅助任务。当前覆盖区域 CNN、空间输入与公共／档间头保留。

## 设计约定

- 原标签函数默认返回两分量不变；新增三分量路径，复用同一批候选渲染。A、B、S 都在有效像素核内积分，除以 H*W*d_ref，RGB 使用均值。
- 新采集读取已完成 footprint_split 的 initial.pt 与 metadata，不依赖旧比较目录的回放；冻结编解码器、参考值、初始归一化和整块留出划分。新数据带独立 schema，旧数据不能用于三项训练。
- 新网络复用原公共／档间价值头预测最终两分量，额外学习非负 B，A=原MSE输出-B。A+B 精确回到原数值主路径；这与直接预测 A、B 的表达等价，同时保留原始函数初始化。
- 主损失为原逐视角公共＋强化 RD 档间数值损失，固定系数1。A、B、S 分量监督以训练集 RMS 归一化，GradNorm仅在三项之间分配，总辅助系数1。排序 KL 乘 tau/s，申请系数1，实际全参数梯度范数不超过数值合成梯度。
- 一次前向，五项梯度微批次累积。默认4096训练／512验证，batch64，64000次样本访问=1000更新；验证与高代价阈值、尺度只用训练拟合，最后一步保存。输出保持轻量review。
- 模型初始输出与旧 footprint 模型相同。能量头初始为训练能量尺度的1%，交叉项对应调整。能量尺度只在训练标签拟合一次。

## 工作顺序

1. 标签数学与精确局部积分测试先失败；增加独立标签路径及采集窗口，验证同一渲染调用次数。
2. 网络初始函数、非负 B、真实重组、训练尺度隔离、固定主权重与全参数梯度预算测试先失败，再实现模型与损失。
3. 采集／CPU训练／精确恢复入口及脚本；验证源文件只读、全程状态恢复、旧schema拒绝、轻量打包。
4. 运行相关定向测试及独立代码审查，修复重要问题，提交推送，给服务器启动代码。

## 执行记录

- 新数学／模型测试先因新接口缺失失败，再实现通过。真实 CPU 采集验证两种 schema 均可恢复，新路径渲染调用次数与旧路径相同。
- CPU 训练中断恢复与连续训练的网络、GradNorm、采样访问和梯度计数一致，原数据文件哈希不变。
- 独立审查发现原始辅助 GradNorm 梯度诊断与实际应用权重相差3倍。新增日志断言先失败，再补充实际权重下的梯度范数和原始诊断范围。
- 旧标签定向回归发现默认函数绑定会绕过运行时替换的诊断函数，改为调用时解析默认函数，保留旧有行为。
- 本轮44项定向检查通过，包含新数学口径、真实CPU局部采集、旧标签核与halo、原入口、固定主权重、续训一致性和数据只读。启动脚本通过Bash语法检查，CLI可用；本地未执行真实CUDA场景全量训练。

## Review Focus

同一候选渲染供旧值与新分量；有效像素无重复积分；能量不经过中心化或q0减法变成负数；最终价值固定权重；验证不参与尺度和温度拟合；所有任务梯度与实际权重口径一致；新旧检查点不混用。
