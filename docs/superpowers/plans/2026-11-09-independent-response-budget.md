# 独立响应分量与分组梯度预算实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. 按任务完成定向测试并记录结果。

**Goal:** 用独立 A／B／S 预测与普通组梯度参考预算，改善收益网络的档间数值精度和更新稳定性。

**Architecture:** 复用当前覆盖区域共享主干、固定标签与报告。A、S 各自保持共同值和档间差异，B 由非负头独立输出；合成后接受原价值损失。先累积两类样本的全参数数值梯度，再按普通梯度范数 EMA 限制高代价梯度，最后施加排序梯度预算。

**Tech Stack:** PyTorch、CPU 固定回放训练、现有 JSONL 检查包。

**Spec:** 本轮用户批准的两项设计；详见 `docs/benefit_independent_response.md`。

## Global Constraints

- 保留旧入口默认行为；新入口直接复用上一轮 `data`，默认 64000 次访问、1000 次更新。
- 编解码器及标签只读；训练／验证隔离；初始化及统计只使用原初始化文件、训练标签。
- 主数值系数为 1；辅助系数和为 1；排序预算在分组平衡之后计算。
- 普通参考 EMA 系数 0.95；首个有效普通梯度初始化参考。缺少有效参考时保留高代价梯度并打印原因。
- 断点保存并恢复预算 EMA、计数、优化器、采样器和随机调度；仅提交本轮文件并推送。

## Review Focus

- 改变 B 会直接改变合成 MSE，并由合成损失反传至 B；A、B 可独立变化。
- 完全相同的候选状态仍严格输出零；B 保持非负。
- 分组预算复用原重要性和采样修正；两组反向与整批梯度严格可比。
- 首批为零或数据仅有一组时仍能学习；非有限梯度不进入 EMA。
- 中断后恢复与连续执行一致，来源标签和旧入口保持原样。
