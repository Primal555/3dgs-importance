# 收益网络训练预算扩展

用户批准增加同一标签的学习次数。新脚本默认 64000 次访问、batch64、1000 次更新。已有 16000 次实验允许保留全部状态续训至累计目标。

实现：恢复校验仅放开预算递增，其他设置严格匹配；完成标记按实际进度处理；保留短训练检查包及历史指标；新脚本更新默认预算。旧目标函数和网络不变。

验证：小数据先完成短预算，再续训，与一次长训练的网络、GradNorm、采样访问数和统计精确比较。错误配置不得改写原 plan，预算缩减应拒绝。新增测试已观察到旧入口预算拒绝和无效参数改写 plan 的失败，再进行修复。定向验证后按项目规则提交推送。

独立审查发现归档前写入新预算会在归档失败时丢失重试依据。补充中断测试复现后，改为先归档旧检查包，再保存新预算；恢复时重试归档。保留原记录和完成后的比较材料。
