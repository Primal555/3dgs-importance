# 网络收益反馈适配

目标：真实正档位干预参与网络学习，历史反馈跟随网络版本，跨窗口残差核对实际上下文。q0 全点反馈保持原设计。

设计：新增独立入口，复用索引修复后的 700 窗口预训练；分配阶段默认在线学习、2000 步、正档位上限 1.0，q0 上限 0.25。保留每步 64 组完整监督和 64 次更新。将已有真实纠偏中的训练点动作加入同一 replay，以已知动作差值监督；不伪造其余档位标签。仅对少量纠偏点补建输入，复用相机及候选缓存，不额外真实渲染。固定验证空间块不参与网络训练。

残差保存真实输入／标签对应 replay ID，读取时由当前网络重算。仅复用相同相机集合及相同块内具体档位的动作；按目标与块可见性描述变化连续衰减。随 replay 淘汰清理引用，不复制大输入。

不同网络版本的正档位预测均值不混用；点再次访问时清理该点旧预测统计，保留概率表、候选访问计数、真实 replay 和全部 q0 历史。概率表继续跨视角累计更新。
