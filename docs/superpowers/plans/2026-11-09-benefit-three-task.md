# 三项收益监督与有效批次对照实施计划

> 执行方式：使用 executing-plans，在当前仓库逐项实现与验证。

**目标：** 保留覆盖区域＋共享特征＋共同／相对双头，分开共同数值、档间数值、正档位排序监督，再比较有效批次8和64。

**设计依据：** 用户已确认上一轮给出的三项监督和有效批次64方案。

**技术：** PyTorch、既有不可变候选回放、CPU离线训练、Bash启动。

## 范围与口径

- 两组均从源实验 `data/initial.pt` 构造相同的原分离预测头，新增覆盖CNN按原种子初始化，全部分支可训练。该文件是历史评估器快照，不称为全随机网络。
- 数值损失沿用原单位与系数，共同项2.5、档间项3（具体由原配置推导）。三项任务独立GradNorm；RankNet仅三对正档位，温度沿用训练标签拟合值。
- 每组默认16000次样本访问。batch8均匀循环、2000次更新；batch64按训练分层比例配额并重要性修正、250次更新。微批8，累积完整任务梯度后才计算GradNorm、裁剪及更新。
- 两组固定相同数据、初始权重、学习率、样本访问预算；batch64组的分层组批属于稳定更新方案，报告中显式说明。
- 统计训练／验证普通与大档间差异样本的regret、数值误差及共享参数梯度。验证集不参与采样、温度、任务权重拟合。
- 源文件只读，支持精确恢复；检查包只含设置、指标、预测和摘要。原在线分配器与残差机制保持原实现。

## 审查重点

- 微批之间不能更新参数或GradNorm；必须先求梯度向量和，再求范数。
- 共同头保留梯度；排序只比较q1–q3，通信成本只加一次。
- 分层配额不会改变期望统计目标，空分层和尾批正确。
- 恢复包含网络／Adam／GradNorm／样本顺序；输出重建不重复训练。
- 样本访问数与优化器步数均报告，普通／重尾梯度来自真实参数。
