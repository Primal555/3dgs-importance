# 独立双阈值熵分配对照

## 已确认设计

沿用完成的 grouped_entropy_stage_one_v1 实验，冻结编解码器和已计算的信息量。按原始 PLY 行序，令 I≤t1 选择 q1，t1<I≤t2 选择 q2，其余选择 q3。t1、t2 独立，允许相等；相同信息量不拆分。保持 0/8/24/48、10 dB、全部输入点保留及原有通信计费。

校准目标保持 D/D_ref+βC/C_ref，继承原实验 D_ref、C_ref、λ_s、校准／测试相机及配对噪声种子。默认同时计算 β=0.1、0.5。采用信息量分位点 0、0.1、0.25、0.5、0.75、0.9、1 的有序阈值组合，并加入接近全 q2 开销的候选；按完整实际成本检查预算。原 η 候选和三个固定档位也进入同一选择集合。完全相同的档位图只测一次。

独立报告校准集上满足 C≤C_q2 的最低失真候选。该项帮助检查原定阶段目标，主实验仍按固定 β 的 RD 选择。全部选择先写入 selection.json，然后评价留出视角。β之间复用真实解码／渲染；源实验缓存仅在编解码器、场景、档位、相机、噪声和失真定义匹配时复用。

输出阈值、比例、完整成本、PSNR／SSIM／LPIPS、β对应结果和 q2 比较。review.tar.gz 保留指标及少量最终图像。独立入口，零优化器更新。
