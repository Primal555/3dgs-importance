# 覆盖区域双头结构上的 RankNet 与 GradNorm 实验

本轮按用户指定方案执行：恢复 `FootprintSplitNetwork`，沿用实验前 `data/initial.pt` 初始化，共享编码器、覆盖区域 CNN、共同价值头和档间差异头全部可训练。已完成的 upgraded 权重只作为评测参照。

## 实现口径

- 复用原始 4096／512 标签、固定归一化和训练集拟合的排序温度。
- 原数值监督为 absolute＋common_weight×common＋pair_weight×pair，其中 pair 包含 q0 在内的六对比较。代数合并为 `(1+2*pair_weight)*centered + (1+common_weight+pair_weight/2)*common`，保持数值及梯度等价。
- 原方向项替换为六对完整 RD 成本的 RankNet 软目标 KL；包括 q0 的三对比较，已知通信成本直接加入。
- GradNorm 只平衡数值恢复、RD 排序两个任务；保留原始均匀洗牌循环和 importance_weight，不新增普通／大差距分层抽样。
- GradNorm 监测共享 `points[2]` 权重和偏置，避免选择只连接某个预测头的参数。
- 默认 CPU、2000 次更新、每 250 次评价；保存末步，不通过验证集选模。保留普通／大差距及去除最大收益后的评价。
- 初始化构造顺序与旧双臂实验一致，检查网络初始权重和初始函数，记录共同头、差异头及共享编码器的参数变化。原始目录只读。
