# RD 概率排序与 GradNorm 训练 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将重复数值监督合并为一项，加入有独立含义的连续 RD 排序监督，并实际平衡普通／重尾任务的更新。

**Architecture:** 沿用独立正档位网络与冻结共同价值。数值目标为 `(1+3*pair_weight)` 倍中心化两分量 MSE；概率排序使用真实完整 RD 差值、独立训练温度与 Bernoulli KL。普通／高差距的数值／排序形成最多四项任务，用 GradNorm 调整权重。固定训练分层抽样保证各任务每批可见，完整训练集无更新预遍历提供初始损失基准。

**Tech Stack:** PyTorch、固定 SpatialReplay、RankNet、GradNorm、JSONL 与 Bash。

**Spec:** 用户已批准直接尝试合并数值约束、连续排序与梯度平衡，不再只增加参数检查。

## Global Constraints

- 复用已有候选区域标签、初始权重及两个旧参照，不采新标签、不渲染、不更新概率表。
- 数值回归两个分量继续共用原物理 RD 尺度；合并时保留等效系数。
- 排序无硬平局门槛、无差值绝对值外层权重；预测与教师均含已知通信代价。
- 温度、分层及损失初值仅由训练数据确定，验证集仅评价。
- GradNorm 使用共享正档输出头隐藏层的实际参数梯度与相对进步速度；网络与任务权重优化器分离。
- 默认 CPU、2000 次更新、每 250 次评价，保留普通／高差距／活跃样本、剔除主要收益记录后的报告。
- 原入口行为保持；默认提交推送，只提交本轮文件。

## Review Focus

- KL 目标接近 0.5 时仍有连续监督；大幅误判不溢出。
- 只有一个非空分层时任务数自动减少；每个启用任务每批都有样本。
- 原始重要性权重在分层内部保留；分层目标改变训练代理，元数据必须明示。
- GradNorm 的梯度目标与训练速度须 detach；权重更新不得污染网络梯度。
- 完整数据基准、采样状态、优化器和任务权重全部可恢复；同源参照校验不能省略。
