# 统一 RD 回归与三档联合监督实现计划

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在固定离线对照上兼顾普通样本误差和高代价错选，完成一组可直接与已有原损失组比较的训练。

**Architecture:** 沿用 SpatialBenefitNetwork、原快照、4096 条固定训练记录及批次顺序。
窗口平均的正档 RD 中心化回归为主目标；逐视角两分量共用原 RD 尺度作辅助；真实 RD 生成联合软选择目标。
全部记录均匀循环覆盖，保留原采集重要性权重；不增加困难样本采样。

**Tech Stack:** Python、PyTorch、现有磁盘回放与 CPU 离线评估。

**Spec:** 本文件记录本轮已获用户认可的两项改动，以及普通和高代价样本同时改善的要求。

## 全局约束

- 新入口读取完成的 benefit_stage_one；从 initial.pt 开始，复用 data_manifest.json。
- 同批次、同种子、相同初始权重和归一化；AdamW 与原对照同样重新初始化。
- 默认执行原对照相同的 2000 次更新；不重跑原组，不调用渲染器或改变概率表。
- 主回归尺度为原 scales.rd；辅助分量共用这一尺度，权重 0.25；联合项沿用原 decision_weight。
- 温度为固定训练记录的非零正档 RD 差值中位数，下限 1e-8。普通／高差距阈值为完整训练记录正档 RD 极差的 Q90。
- action_gap 只监督已记录的两个状态，不补造其他档位标签。
- 报告所有样本，以及按训练阈值固定划分的普通／高差距子集。全局和逐视角分量误差、选档 regret、方向误判、高代价错选均保留。
- 当前仓库实施，保留其他未提交内容；定向验证后提交推送。

## 审查重点

- 真实旧 initial.pt 没有完整网络配置，需从同源不可变 benefit_network.pt 恢复并核对。
- 相机平均后形成选档目标；逐视角误差仍有辅助梯度。
- 通信成本计入目标一次，MSE 和已加权结构项保持物理比例。
- 正确预测和共同平移时，联合项与主回归的最优点一致。
- 不读取验证标签拟合尺度或阈值；源文件不变，结果只写新目录。
