# 无信道、学习式 XYZ 的分阶段语义自编码实验

状态：设计待用户审核；本文件不代表实现或测试已经完成。

## 1. 已确认的目标与边界

用户希望在当前模块化研究线之外新增独立实验，先验证语义表示本身能否准确恢复完整 3DGS。顺序为：位置恢复 → 属性恢复 → 联合微调。本轮不建立信道编码器、信道解码器或档位分配器，不截取前缀、不归一化发送功率、不注入噪声，也不传递 16bit 或其他逐点坐标旁路。已有通信实验、配置和 checkpoint 格式保持不变。

本轮不使用信道空间去噪。属性语义解码可在恢复 XYZ 后利用预测位置进行空间上下文聚合；这不构成位置恢复的前置依赖。

先只运行 Truck，随机初始化。已有运行目录只提供数据路径、分组参数、属性统计和相机划分，不提供网络权重。不存在从历史失败实验中挑选初始化的隐含步骤。

## 2. 代码核对结论

- `gaussian_jscc/modular_codec.py::decode_representation` 当前强制要求外部 `delivered_xyz`，将其与预测属性拼接；不能通过删除坐标文件来得到学习式 XYZ 模型。
- `gaussian_jscc/modular_core.py::SemanticDecoder` 当前只有属性输出头，无 XYZ 预测头，而且会 detach 输入坐标。
- `gaussian_jscc/modular_config.py` 强制可靠 16bit 坐标，不能给旧配置简单切换 `position_delivery` 而保持接口含义不变。
- `gaussian_jscc/local_response.py::local_response_loss` 明确排除 learned XYZ；它的孤立 Gaussian 响应以相同中心为原点，本身不监督位置。应提取共享的“属性响应”计算，保留旧入口限制，并由新实验显式调用。不得谎报为位置训练损失。
- 当前 PointNet++ 式聚合将用于邻域选择的位置 detach。离散邻域索引本就不要求可导，但联合微调必须另有连续的预测 XYZ 输入路径；不能误称邻域选择能向坐标反传。

## 3. 结构选择

沿用用户已认可的方案：在同一个语义模型内显式区分位置表示和属性表示。不采用“完全共享 latent，只在末端加一个 XYZ 头”，以避免属性阶段改变共用特征而破坏已学好的位置；也不恢复历史的公共块中心加局部残差结构。

```text
发送端
  XYZ ─────────────→ position_encoder → y_xyz ──┐
  XYZ + 其他属性 ──→ attribute_encoder → y_attr ─┴→ y = concat(y_xyz, y_attr)

接收端（只读取 y、有效槽掩码与已声明的全局元数据）
  y_xyz → position_decoder → 预测 XYZ
  y_attr + 预测 XYZ → attribute_decoder → 预测其他属性
  预测 XYZ + 预测其他属性 → 完整 Gaussian → 渲染器
```

`encode_representation` 和 `decode_representation` 是明确分离的接口。接收接口不接受目标属性、原始 XYZ、原始邻接表或原始块中心。训练目标通过损失入口独立提供，不通过 decoder 参数提供。

### 3.1 位置部分

- 输入只包含本点 XYZ，不包含方向、尺度、扁平度、透明度或颜色。
- 起始实现采用逐点残差 MLP 编码和解码，默认隐藏宽度 96、3 个残差块。它是本轮的位置精确读写基线，不再先叠加多层跨点注意力。
- 位置 latent 默认 32 个实数维度，可配置。不使用依赖当前样本的 LayerNorm/均值池化来消除绝对数值信息。
- 输出逐点绝对归一化 XYZ，使用无 sigmoid 的仿射读出，再通过场景全局归一化的逆变换得到世界坐标。没有从原始坐标到预测坐标的跳接、手工参考信号或固定坐标重复观测。
- 宽度、层数、维度是工程起始配置，不宣称经过最优选择。

### 3.2 属性部分

- 保留当前属性语义表示的能力：默认属性 latent 为 48 个实数维度，使用已有逐点自身路径和 PointNet++ 式空间上下文。
- 编码端可使用原始 XYZ 构造空间上下文；这属于发送端合法输入。
- 解码端所有位置输入和邻域构建只能使用预测 XYZ。
- 属性输出沿用当前 scale、rotation、opacity、DC、SH 格式；不在本次同时更换成其他形状表示。
- 联合阶段允许预测 XYZ 通过连续的坐标嵌入影响属性解码。邻居索引、FPS 等离散选择仍停止梯度，需在日志/文档中明确区分。
- 位置与属性编码参数不共享；位置 latent 不依赖属性 encoder。属性阶段冻结位置 encoder 和 decoder 后，位置数值必须保持不变。

默认合并后的 `y` 为 80 维实数。这是无量化的语义表示宽度，不是复符号数，也不构成带宽节约的证据。本轮不承诺将来 8/24/48 等预算足够恢复该表示。

## 4. 接收端可用信息

允许：模型权重、属性反标准化统计、场景全局包围盒/归一化参数、有效点数、块长和传入序列顺序。以后接入通信时，这些元数据必须列入传输协议和成本。

禁止：逐点原始/量化 XYZ、逐块原始空间中心、原始邻居索引、原始属性、目标图像。模型对原场景的记忆能力不等于跨场景泛化能力；本轮只验证单场景表示重建。

Morton 排序只在发送端执行。接收端按收到的槽位/块边界处理，不重新用原始坐标排序。逐点监督和属性对应关系由发送序列维护，不通过恢复后最近邻匹配偷偷替换。

## 5. 三阶段训练

默认预算为 5000 / 5000 / 1000 次优化器更新，全部可通过启动参数覆盖。更新次数不是取样块次数；位置累计 2 个独立小批次后进行一次更新，不能将 5000 次更新悄悄缩成 2500 次。

### A：位置恢复

- 只训练位置 encoder、decoder；属性参数不参与 Adam。
- 目标：原始 PLY 中逐点对应中心的世界坐标 MSE。
- 定义 `L_xyz = mean((XYZ_pred - XYZ_source)^2)`，平均包括有效点和三个坐标维度，不包括 padding。它不是欧氏距离均值，也不使用 Gaussian 薄轴尺度放大位置梯度。
- 默认 LR 固定 `1e-4`，无默认阈值为 1 的梯度裁剪，无拒绝更新/步长回退。
- 每次记录 MSE、坐标梯度、参数更新量；位置渲染诊断为预测中心配合原始属性，仅用于隔离位置误差。

### B：属性恢复

- 冻结整条位置 encoder、decoder；属性 encoder、decoder 可训练。切换时清除冻结参数梯度、建立仅包含属性参数的新 Adam。
- 默认 LR 固定 `1e-4`。
- 常规更新使用现有孤立 Gaussian 局部响应 RGB MSE，比较形状、透明度、方向颜色产生的响应；它不监督位置，也不包含人为逐属性加权和。
- 每第 4 次更新替换为独立方向颜色 MSE，8 个方向，训练相机方向与均匀球面方向各半。颜色更新时非颜色输出头的梯度设为 None，避免 Adam 动量仍更新这些头；属性编码/共享解码特征仍允许变化。
- 颜色步骤与普通步骤计数独立记录，但合计仍为 5000 次更新；不额外隐藏增加更新次数。
- 属性 decoder 始终使用预测 XYZ，不在该阶段偷偷切回原始 XYZ。损失计算中的目标属性/方向仅作为训练教师，不传入接收接口。

### C：联合微调

- 解冻位置和属性两条语义路径；只做 clean 全场景渲染，不出现信道模块。
- 每次更新以原始 PLY 在同相机下的 RGB 渲染 MSE 为目标；照片仅评估，不替换为训练教师。
- 默认位置参数 LR `1e-5`、属性参数 LR `1e-4`，保持固定，不新增未经讨论的 MSE 混合系数或硬性拒绝机制。低 LR 只能降低漂移风险，不保证消除漂移。
- 默认 1000 次全部为联合渲染更新，不插入额外颜色或位置更新，以便观察联合渲染本身对颜色和中心的影响。
- 每次验证始终测量原始 XYZ MSE/偏移及方向颜色误差，不能只用渲染 loss 掩盖几何退化。若该阶段漂移明显，再独立讨论位置锚定或交替更新，不在本轮悄悄加入。
- 使用现有 replay 全场景反向以控制显存；重算时保证块、有效掩码与模型状态一致。

阶段按明确步数顺序执行；不自动挑历史 best 权重，不以失败 gate 跳过阶段。A/B 最末状态原样进入下一阶段，另外保存 best/last 供分析。非有限损失或预测明确中止，保存最近完整状态和错误，不继续更新。

## 6. 观察、保存与断点

所有产物位于同一个 OUT，不建立并列的 render_history 目录。

- 每 500 步：固定验证视角，记录 clean full、center-only、attribute-only 三条诊断路径。full 只有预测 XYZ + 预测属性，其他两条明确标注为教师替换诊断，不是部署结果。
- PSNR、SSIM、LPIPS 分别对原始 PLY 和照片报告。LPIPS 只用于评估，缺失依赖/权重时明确报错或明确标记 unavailable，不能输出假 0。
- 位置记录：三个轴的有符号平均偏移，轴向 MSE、`sqrt(mean(||error||^2))` 距离 RMSE、距离分位数、去除全局平移后的 RMSE、去除逐块平均偏移后的 RMSE。明确区分欧氏距离 RMSE 和逐坐标 RMSE。
- 属性记录：分属性标准化 MSE、未截断方向 RGB MSE、RGB 有符号偏差。不同阶段/不同目标 loss 分图，不合并成能直接横向排名的总 loss。
- 保存代表图：初始化、A 结束、B 结束、最终。每 500 步写指标，不默认保存所有视角图片；可选 `--image-every 500` 供定位阶段开启。
- 保存每 500 步 checkpoint、最新状态、各阶段末状态。包含模型配置/权重、当前阶段与局部步数、Adam、Python/NumPy/Torch CPU/CUDA RNG、输入场景指纹、相机划分、归一化元数据和监督协议。
- `--resume` 为同 OUT 精确续训；默认随机启动，不隐式载入当前模块化 JSCC 或历史 center checkpoint。
- 图表至少包含三阶段分别的目标曲线、位置精度与偏移曲线、三条诊断路径画质、颜色误差曲线。

## 7. 计划文件与复用边界

新增独立模块，建议命名：

- `gaussian_jscc/learned_xyz_semantic.py`：配置、位置/属性模型、仅 latent 的接收接口。
- `gaussian_jscc/learned_xyz_training.py`：阶段参数边界、三种目标、状态保存/续训。
- `gaussian_jscc/learned_xyz_evaluation.py`：全量点误差、教师替换诊断、图表与渲染。
- `gaussian_jscc/learned_xyz_experiment.py`：Truck 数据加载、CLI 和阶段驱动。
- `scripts/test_learned_xyz_semantic_truck.sh`：显式 GPU、随机初始化、nohup 兼容启动。
- `docs/learned_xyz_semantic_truck.md`：用途、限制、启动/续训、字段定义。
- 独立测试文件，避免改写现有通信实验的默认行为。

仅提取确有必要的属性局部响应共享计算；不能取消旧 `local_response_loss` 的安全限制。尽量复用场景读取、已有响应/颜色计算、渲染任务、指标和 RNG 保存工具，不复用硬编码“可靠 XYZ”假设的通信评估入口。

## 8. 验收与风险

实现前先写测试覆盖：

1. 任意改变训练目标 XYZ 不影响 `decode_representation(y, mask)`；接收端不接受原始位置。
2. A 只有位置参数更新；B 位置参数和逐点预测保持一致；C 两条路径均有有限且有效的梯度。
3. 属性 decoder 使用预测 XYZ；联合渲染至少存在直接中心梯度和连续坐标条件梯度，不能被旧 detach 误截断。
4. padding、空块、有效点计数不改变目标定义，颜色非颜色头无动量更新。
5. 位置 MSE 和各 RMSE 的定义通过人工可算样例验证，逐点/逐块对应顺序正确。
6. 保存/续训恢复 Adam、阶段边界与 RNG；阶段末启动不跳步、不重复执行。
7. 可用 CPU 执行的小型数值学习测试证明位置支路可拟合样例，不将 CPU 检验等同于 CUDA 全场景效果。
8. 现有模块化通信相关回归测试保持原行为；服务器 GPU 烟雾测试另行标明是否真正执行。

风险：位置精度可能仍不足；属性依赖错误几何时难以恢复；全场景渲染可能再次让中心漂移；80 维 clean latent 可能难以在有限信道预算下保持精度。它们都通过独立阶段和诊断路径显式暴露，而不是先假定解决。这个实验通过也只说明表示可重建，不说明噪声通信、传输成本或多场景泛化已经解决。
