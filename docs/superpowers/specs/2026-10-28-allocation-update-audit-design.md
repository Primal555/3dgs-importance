# 分配器实际更新代价的服务器短审计

用户已要求先实现服务器检查，再在其运行期间开始真实结果的本地统计检查。

## 范围与方案

加载已完成 calibrated-v2 分配实验的 best_rd 检查点，每组默认20个训练视角窗口、每窗口4视角、最多32次反事实渲染。冻结概率表和编解码器。每窗口从相同收益历史起点计算一次假想更新，随后原位恢复历史；候选调度计数允许推进，以覆盖更多点。源检查点只读。

复用训练 kernel，在返回动作代价之前提供可选 inspector 回调。审计时关闭训练精确覆盖，通过真实 accumulate 路径计算“加入本窗口近似观察，但尚未见本窗口精确标签”的最终代价。回调只读取数据并独立渲染标签。默认训练路径不启用回调。

与手写一套近似历史更新公式相比，复用实际 accumulate 可避免两套公式漂移；与完整续训相比，冻结概率与逐窗口恢复可隔离收益评估误差。

## 比较项目

正档位比较当前一阶、当前一阶加旧纠偏、真实历史更新代价、精确换挡结果。通过同一个 BoundedMirrorTable 的单点副本测量假想概率比变化，不更新真实概率表。

q0每个抽查点完整取得 q0/q1/q2/q3 的相对失真，当前布局的状态直接复用基准，其余3种状态各渲染一次。历史就绪时用当前正档位条件概率混合，形成与最终 keep_costs 匹配的精确“保留期望减删除”标签；历史未就绪或关闭记忆时，使用实际回退分支的采样档位失真加期望通信成本。另外按本次采样档位单独比较一阶与旧纠偏。固定32次预算下，默认26个正档位动作加2个q0点的三状态反事实。

全部预测在精确标签进入任何学习路径前固定。通信项沿用训练边际代理，与画质预测误差检查分开；不宣称逐动作精确压缩包成本。只使用已有 allocation_train_view_names，不使用校准或测试反馈。

## 输出与验证

独立输出 plan.json、actions.jsonl、windows.jsonl、summary.json、complete.json；不保存图片、PLY或新模型。校验教师/概率表/收益历史保持不变。开发只做CPU小型正确性测试；实际两组实验的本地统计在用户启动服务器后进行。
