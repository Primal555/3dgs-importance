# 固定地图的换挡收益归因测试

用户同意先暂停停滞的直接分配实验，进行一次集中测试，再依据结果制定修正。本轮新增只读测试入口，不修改分配规则或网络，不在原输出写入文件。

- 从 direct RD 的最新 checkpoint 固定地图、编解码器、收益网络、目标归一化和数据划分。
- 延续该 checkpoint 的候选调度和视角调度，默认收集一个 10 窗口周期，形成一批新的可追溯提案。历史被拒绝提案未保存点编号，不能声称复现历史某一次验收。
- 分层抽取高分、中分、低分的已选动作及普通候选替代动作，默认各 16 个，保留源行号、编码块、原／新档位、预测排序和采样条件。
- 复用整块候选解码、固定噪声槽和精确局部渲染标签。对相同动作计算：原候选视角与噪声的网络／真实收益；更换为校准视角但保留相同噪声的收益；原验收校准视角与两次噪声的收益。每个点另外计算完整通信开销差，区分预测误差与成本代理误差。
- 在校准条件下比较单点收益之和与同组完整场景真实收益，并单列图像交互与通信编码非可加性。评估原完整／半数／四分之一提案，以及高分样本的不重叠小组。
- 少量点用原完整渲染器检查局部标签一致性，报告误差；若超过容差则停止机制归因结论，优先检查执行一致性。
- 仅读取训练／校准视角。测试视角不用于本次归因或选择，不调参、不更新网络。分层结果分别报告，不把高分样本误判率称为总体误判率。
- 输出 summary.json、逐动作 CSV、分组 JSON 和小型 review.tar.gz。不保存重建图、replay、网络副本。支持只读 dry-run。
- 启动脚本默认拒绝与同一源实验的活跃训练进程并行。显式 PAUSE_SOURCE=1 时只暂停同 UID、同模块、同绝对 OUT 的进程，等待退出后读最近原子 checkpoint；未保存窗口可重算。

结果对应修正：同条件单点预测错则处理高分选择分布及监督；视角／噪声差异主导则对齐评价任务及采样；单点正确但组合恶化则处理提案交互和验收分组；成本代理偏差显著则修正边际成本。统计不足或执行一致性未通过时明确标记，保留各项原始数值。
