# 精确纠偏与有效证据分配器

用户已同意在当前结构证据分配器中集中实施两项改动，继续使用当前仓库，并要求提交推送。

## 范围

冻结同一编解码器，保持 MSE＋SSIM、显式 beta、0/8/24/48、单次训练采样、十次部署、2000 步和 32 次精确检查预算。升级现有 structured 入口为 v2；v1 统计类保留供历史测试和复现。v1 分配检查点不作为 v2 的 exact resume，从原冻结教师重新学习概率。

## 方案与取舍

采用独立纠偏历史及均值不确定性。仅提高精确检查权重仍会被后续近似观察稀释；统一增大学习率会同时放大错误反馈。独立纠偏按“原始点、当前动作、替代动作”保存，保留与删除分开记录，仅保存真正检查过的条目。两分量分别累计，通信差价仍逐步重算。

精确残差为 `delta_exact - delta_proxy`。近似均值只累计近似观察；残差使用独立衰减权重，普通近似观察不能增加或稀释该权重。查询时根据时间和块内实际档位分布的变化平滑减弱旧纠偏。当前精确动作直接采用本步真实差值；其他动作使用近似均值加匹配纠偏。不会给未检查的动作伪造精确记录。高损失的纠偏失败进入已有风险排序，精确检查总数不增加。

有效样本量使用指数权重的 Kish ESS，并用实际见过的训练视角数除以每窗口视角数设置保守上限。视角覆盖使用 CPU 位集，重复同一视角不能无限提高置信度。均值标准误为分量标准差除以有效样本数平方根；再合并纠偏的不确定性。置信度以完整 RD 动作差异衡量信号，包含确定的通信差价，保留 0.1～1 的连续缩放及 0.25 的最大 log-odds 步长。q0 置信度按实际用于更新的条件混合历史计算。

## 边界与验证

仅训练视角进入有效样本统计，不使用校准和测试反馈学习纠偏。块分布只作为上下文新鲜度近似。精确记录采用稀疏 CPU 张量；不新增渲染，不扩大 GPU 场景缓存。保存纠偏、权重平方和及视角位集，分段续训须与连续运行一致。诊断记录纠偏覆盖、校准前后误判与损失、有效样本量和置信度。

定向验证包括纠偏持续性、动作隔离、上下文/时间衰减、重复视角、稳定证据提高置信度、当前精确值优先、空候选、全 q0、MSE 模式、RNG 不变、冻结教师、入口与完整恢复。服务器实际画质和速度由新实验测量。
