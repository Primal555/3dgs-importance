# 物理特征收益评估实验

## 目标与边界

在冻结的 0/8/24/48 编解码器上，检验紧凑、可解释的输入和 RD 决策监督是否改善收益预测。保留 pixel_benefit 独立实验入口。沿用准确的整块换挡、配对噪声、局部渲染标签、训练验证块隔离和实际部署评价。

## 输入与输出

- 静态属性：不透明度、尺度、体积、SH 高频能量、DC 灰度、真实 XYZ 的近邻距离，以及全局／局部标准化统计。KNN 默认 32，分块查询一次并随断点保存。
- 视角信息：按实际深度顺序累计 alpha×T、遮挡前 alpha、可见贡献的平方和与峰值、贡献加权的参考 RGB 和当前 RGB 残差。每个视角计算一次，所有候选复用。
- q0 的位置和形状使用零存在权重的源属性探针，基线图像保持不变；遮挡前 alpha 独立于 early exit 累计。
- 候选信息：目标点和完整变化块的颜色、透明度、尺度、投影形状、存在状态及其相对 q0 的变化。完整块统计包含邻居随换挡发生的变化。
- 每个状态共享 MLP，预测 MSE 和加权结构项的整体变化；输出相对 q0 的 3×2 数值。相同输入状态严格产生零差值。标签使用现有精确干预渲染，立即积分保存，无需保存密集像素标签。

输入统计是有限维描述，仍有信息损失；基线可见权重在候选形状变化时只是条件特征。候选真值仍重新投影、排序、合成，包含跨 tile 与遮挡变化。

## 学习

前 50 窗口仅从训练标签和特征拟合固定尺度。随后每窗 16 次更新，默认 200 个预训练窗口；分配阶段 2000 步。每窗 64 个完整干预组，四个视角。

损失包括分量 Huber 回归和四动作 RD 成对排序。排序目标在组内多视角平均后加入实际通信成本，按真实决策代价加权；接近零的真实差值不参与排序。默认排序权重 1、相对容差 0.02，均属于本实验待验证设置。AdamW、权重衰减 1e-4、隐藏层 64/32、共享状态 dropout 0.05。

保留最新权重和完整优化器、随机数、replay 状态。记录回归损失、决策损失、训练选择 regret、验证方向误判／regret／共同偏差及固定档位基线。

## 验证

CPU 验证精确标签等价、可见性统计、状态置换、q0 锚定、近似平局、代价加权梯度、训练集尺度隔离、断点续训和旧入口兼容。服务器启动时运行现有渲染一致性检查及新增统计的 CUDA／CPU 对照。
