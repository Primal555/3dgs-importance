# 预算约束的逐点 Gaussian 档位分配设计

状态：待用户审核；本文件不表示代码已经实现。

## 1. 目标和边界

在给定 SNR、发射功率和一次场景交付的总通信预算下，学习各 Gaussian 的保留状态与正档位，使接收端的多视角渲染失真尽量小。

- 独立实验入口，保留 `successive_allocation` 及其 checkpoint、日志格式和训练行为。
- 沿用 successive 编解码器、q0/q1/q2/q3 = 0/8/24/48 个累计复符号、可靠 16bit XYZ、实际 binary16 块尺度。
- 不重训已有编解码器。第一轮只优化场景专属概率表，冻结全部编解码器权重和属性统计量。
- 保留单次硬采样学习、十次规则部署，以及所有关闭点的 MaskGaussian 式反事实反馈。训练时不物理删点。
- 不规定 q0、q1、q2、q3 的数量或占比，不引入每块 q0 反馈数量上限。
- 输入支持已完成的 successive Joint A，以及已完成的 successive 多场景共享模型；初始化后按所选场景建立新表。未完成训练、缺少统计量或场景身份不一致的输入必须拒绝。
- 初版只训练一个显式选择的场景；同一共享模型可分别对其他训练场景运行。heldout 场景不能隐式进入分配训练。

## 2. 预算及失真定义

主问题为 `min E[render_MSE] subject to C_deployment <= B`。失真继续使用原 PLY 渲染图的 RGB MSE，不同时更换为 SSIM/LPIPS 损失。PSNR、SSIM、LPIPS 分别对源 PLY 和真实照片报告。

预算参数必须显式提供一个：

- `--budget-total-uses B`：整个场景的总复信道使用次数；
- `--budget-ratio-to-q3 r`：以同一场景、同一输入模型实测全 q3 总成本为基准，预算为 `floor(r * C_q3)`。

两种参数互斥，无隐式预算默认值。预算基准在初始化时固定并保存，精确续训不得重新测量后替换。

总成本包括模拟属性 payload，以及可靠 XYZ、完整元数据/档位表、尺度流折算的复信道使用。可靠侧流沿用输入实验明确记录的净 bit/use 假设，分别保存真实字节数和折算假设；共享模型权重不计。

训练期使用符号精确成本和坐标/压缩侧流代理求导。控制、模型选择和最终预算判定使用实际十次部署档位和真实编码侧流的成本，不把概率期望当作硬预算验收。

## 3. 预算价格控制

采用 `L = D / D_ref + lambda * (C_proxy / B - 1)` 的拉格朗日求解形式。`D_ref` 为初始化全 q3 在校准视角上的平均 MSE，只用于固定损失尺度，不构成画质容忍度约束。

- lambda 是非负预算价格：实际部署超预算时提高，预算富余时降低。
- 控制间隔默认 25 次分配更新；对实际 `C_deployment / B - 1` 使用 EMA 后更新价格。
- EMA 系数、初始价格和控制步长均作为显式参数写入训练配置，不能宣称是文献最优参数。
- 预算控制只需部署档位和字节核算，不为每次价格更新做全场景渲染。
- 保留固定预算、lambda 轨迹、期望成本、采样成本、十次部署成本四条记录，区分求解器与真实交付。
- 未能满足预算时明确报告 `budget_unmet`，不强制删点、不自动填充成全 q0、不把最低违规解标为可行解。

## 4. 概率表与更新

继续使用独立保留概率和条件正档位概率：`p_i(keep)`、`p_i(q1,q2,q3 | keep)`。默认保留概率 0.99，正档位均匀初始化。

更新以多视角画质和成本组成的局部收益为依据。采用保留收益幅度的概率镜像更新，避免微小但持续的成本梯度经逐行 Adam 归一化后成为近似固定幅度推进。

- 同一分支的画质和成本项共用固定全局尺度，不按单点独立归一化。
- 保留分支沿用完整 masked-render 门控反馈，所有本轮关闭点均有反事实路径。
- 正档位分支只在获得新的候选评价时更新对应行；其他行的概率保持不变，不对未评价行执行单独的成本降档更新。
- 不把缺失评价填为零收益。保存每点评价次数、最后评价更新编号和完整轮换覆盖次数。
- 使用 log-domain 实现、减去最大值后归一化，避免数值溢出；数值稳定处理不得生成档位数量配额。
- 概率步长和预算价格控制步长独立配置、独立记录。

镜像更新及一阶收益仍是离散问题的近似求解；实际部署指标决定最终方案，不能以代理目标下降代替预算与画质验收。

## 5. 实际混合邻域下的正档位收益

替换当前“块内所有保留点一起换成 q1/q2/q3”的候选生成方式。

1. 固定本轮实际混合档位、保留集合和通信噪声。
2. 各块按可恢复的轮换游标选择一个实际保留目标点，各块可并行。
3. 邻居档位保持不变，只改变目标点的正档位。
4. 重算受影响块的信道发送、块尺度、信道恢复及语义解码。q1–q3 的保留集合不变，复用实际语义 latent。
5. 当前档位复用实际结果，其余两个候选重算；统计受影响块内全部保留点的属性变化。
6. 用实际多视角渲染对场景参数的梯度与候选变化做内积，得到局部一阶换档收益。

候选应计入功率归一化和邻居恢复变化，不能只提取目标点的输出差。候选路径不更新编解码器，不暴露未发送符号或源属性给真实接收端。

q0 的门控反馈覆盖与此轮换调度独立。真实删/留干预的核验必须重算保留集合变化带来的上下文，不能复用不匹配的语义 latent。

小规模真实换档重渲染用于检验一阶收益的符号、排序和误差。核验抽样不限制生产训练中的 q0 反馈数量，也不以随机两次整场景损失差更新所有点。

## 6. 多视角窗口和运行时间

- 每次实际分配更新固定概率和采样，对同一个通信恢复场景默认使用四个训练视角。
- 视角采用随机打乱后的覆盖式遍历；调度器状态写入 checkpoint。
- 逐视角渲染/反向并平均梯度，不同时保留四个渲染计算图。
- 每个窗口只更新一次概率表，计为一次真实更新；不能把四个视角记为四步。
- 训练窗口视角数可配置，比较四视角与两视角的质量、覆盖和耗时；不预先保证四视角总训练更快。
- 保留同一步语义 latent、实际恢复、q0 反事实复用及 replay，禁止跨更新复用受概率表或模型变化影响的结果。
- 单点候选按原块批处理、候选逐个释放；不常驻所有点所有档位的全场景预测，也不把四份网络图同时放入显存。
- 每步避免完整高等级坐标压缩；真实成本核算只在控制/验证/导出节点执行。保留集合未变时复用对应坐标成本缓存。
- 详细 GPU 计时默认每 10 次更新一次，使用 CUDA events 聚合，避免每个块同步。

记录实际/候选编解码、q0 路径、各视角渲染与反向、概率更新、预算核算、预算控制、候选覆盖、显存峰值。阶段汇总给出步耗时 p50/p90，区分验证时间与优化时间。首先测量新旧路径的候选调用数和显存，再在服务器比较 CUDA 时间，不能按理论调用数宣称实际加速。

## 7. 训练、选择与数据边界

- 初版默认 2000 次真实分配更新；同时报告正档位候选完整覆盖轮数，不宣称与旧版 2000 步具有相同反馈覆盖。
- 第一轮默认不进行联合微调，先验证冻结编解码器时的同预算独立收益。交替联合微调作为后续扩展，不在本轮悄悄实现成同时更新三个编解码模块。
- 从原训练视角中独立保留校准视角，训练窗口不得采到；原最终测试视角保持只读。
- 预算控制基于实际部署成本；checkpoint 质量选择基于校准视角，最终测试不能反向决定 lambda、步数或模型选择。
- 保存满足实测预算的最高校准质量 checkpoint，绑定对应 codec 和离散档位，不能把旧档位配到变化后的 codec。
- 若无可行 checkpoint，保存诊断和最低违规候选并明确标注，不能作为满足预算的正式部署结果。
- 十次部署使用固定、保存的 seed，接收端读取发送的档位表，不重新抽样。

## 8. 输出与复现

所有内容放在同一个实验目录。保留逐步 JSONL、预算控制日志、候选覆盖与收益核验、精简率失真表、概率表/实际档位、best-feasible 与 latest checkpoint。

只在初始和最终/选中部署端点保存代表视角图，包括恢复图与档位贡献着色图；中间验证不保存大量图片。q0 无可见 splat，图中背景不得标注为删除点分布。

精确续训保存：概率表、预算价格/EMA、优化更新计数、块游标、逐点评价次数、视角调度器、全部 RNG、模型与场景身份、预算参考与成本假设。临时计算缓存不保存。

## 9. 实施验收

1. 未指定预算或冲突指定预算时预检失败；预检无渲染、无输出写入。
2. 预算控制超预算时价格提高、预算富余时降低，状态可精确续训。
3. 硬前向、尺度帧与 RNG 和相同离散档位的实际通信路径一致。
4. 候选只干预指定点，包含邻居响应；不修改真实邻居档位，不污染真实前向或 RNG。
5. 所有 q0 有门控反馈，未评价正档位行不变化，块/视角覆盖可恢复。
6. 多视角流式梯度与同一候选场景的直接平均梯度一致。
7. 所有编解码器权重和统计量在冻结分配前后逐项相同。
8. 概率期望达标但十次部署超预算的样例必须判定为不合格。
9. 成本包括 XYZ、完整元数据和实际尺度流，压缩成本不在每点候选循环中计算。
10. CPU 小模型与可微合成渲染覆盖端到端保存/续训，定向测试通过后提交推送；不跑全仓历史训练回归，不在本机启动完整场景长训练。
