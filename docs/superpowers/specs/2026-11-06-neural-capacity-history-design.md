# 正档位收益网络容量与完整历史回放

用户批准方案一：在已经有效的 neural_correction_allocation 上，仅提高网络宽度和历史标签保留范围，建立独立实验入口。

- SpatialBenefitNetwork 隐藏宽度 64→256，参数 26,946→206,082，保留层数、输入、聚合、输出与损失。
- 全部训练标签保存在磁盘，内存 LRU 缓存有界。历史样本不因容量淘汰；验证样本独立固定。
- 沿用 25% 均匀、50% 最少访问、25% 困难样本的抽样分布及精确重要性权重。索引维护优先级、访问数和记录位置，避免每次抽样扫描完整历史。
- 预训练 700 窗口，前 50 窗口拟合固定尺度；随后自动进行 2000 步分配并在线更新网络。q0 密集反馈、概率表、步长、纠偏、教师、编解码器冻结和 RD 口径沿用有效版本。
- 新入口使用独立输出，从随机收益网络和新概率表开始。现有入口维持原默认值及有限回放行为。
- 断点包含历史索引、访问数、随机数与磁盘分片清单；输出 review.tar.gz 用于下载检查，完整回放留在服务器供恢复。

比较方案：仅加宽＋完整历史已获批准；增加残差层留待后续。
