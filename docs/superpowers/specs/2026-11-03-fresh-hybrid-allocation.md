# 固定收益网络、从头训练分配器

用户明确要求下一版固定收益网络，从头训练分配器。新入口读取原混合实验的 allocation/plan.json 与紧凑 benefit_network.pt，不读取或复制旧分配 checkpoint，不重复收益预训练。

默认完整分配 2000 步，q0 保留先验 0.99、正档位条件概率均匀。历史、真实纠偏、信任度、候选计数、相机调度及随机种子从新运行初始化。复用原配置中的编解码器、场景、RD/SSIM/通信条件、空间输入、候选规则及评估预算。默认正档位独立上限 1.0，支持显式不限幅与上限 0.25；q0 算法和上限沿用原配置。

输出为独立目录，固定收益网络副本与 SHA256 记录进入新运行。恢复只读取本轮完整状态与固定网络，不依赖原分配目录仍存在。源网络初始更新次数保留且从头到尾冻结。启动打印阶段信息，避免无日志等待。

默认仅支持原 dense_keep_neural_tiers_v1 冻结混合入口作为来源；本轮保持其空间输入一致。source/output 必须隔离。最终保存初始/选中图、档位图、末步指标和 q2/q3 同条件对照，review 包排除 checkpoint 和网络。

验证：旧概率和历史非零时新首步仍为初始状态；删除/隐藏旧 checkpoint 后可启动；源文件 hash 不变；收益权重冻结；相同种子初始化可复现；精确断点恢复；源目录隐藏后仍可恢复；原入口兼容；非法嵌套目录及切换恢复上限拒绝。
