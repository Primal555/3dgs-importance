# 密集一阶保留与空间网络正档位实验

用户要求从头训练收益网络 700 窗口，随后自动进入完整分配阶段。沿用当前冻结的 successive 多场景编解码器；Truck、0/8/24/48、10 dB、可靠 XYZ 和尺度路径、MSE＋SSIM 归一化 RD、十次部署保持一致。

采用最后的空间价值网络及软方向 KL 损失，从随机权重预训练 700 窗口，前 50 窗口拟合尺度，此后每窗口 64 次网络更新；概率表始终固定。默认从 700 窗口末步网络开始分配 2000 步，网络冻结。提供显式 online 模式；该模式继续采集当前候选的完整标签、更新网络，并记录额外监督开销。

分配底座为 calibrated_structured_allocation_v2：保留分支全点存在门控导数、历史、置信度与纠偏不变；正档位候选按旧 coverage_demand 两轮选择。仅正档位数值近似替换为空间网络的 V(q)-V(current)，共同 q0 偏差在差分中抵消，通信差价仍解析计算。两分支沿用镜像更新，keep_lr=0.1、tier_lr=0.4、max_log_odds=0.25，默认 beta=0.1。正档位网络值继续进入原有历史与有限纠偏；其数据来源明确标记为 neural，旧日志字段保持兼容。

默认冻结有助于先判断已有收益网络接回分配的效果，避免再次将评估器在线退化混入主结果。online 模式的额外标签与训练不属于旧版等预算对照。完整分配期间编解码器始终冻结，网络仅负责正档位。正常系统联动可以改变后续的保留轨迹，但任何网络输出都不得覆盖 keep_costs。

效率要求：复用本轮实际 q、语义特征、实际解码和同一噪声；禁止再次采样另一场景。复用已有 batch64/128 的合并投影、空间特征缓存和网络批量推理。旧正档位候选解码在 neural 模式下跳过，仅计算解析档位/尺度差价。四状态候选仍用于当前空间网络输入。

自动流程输出为 OUT/pretrain 和 OUT/allocation，并导出单独的紧凑收益网络 checkpoint。分配恢复使用紧凑网络文件；冻结模式无需读取预训练 replay。online 模式拥有独立 replay，以硬链接或复制初始化活动训练/验证组，原训练输出保持可恢复。checkpoint 包含在线网络、优化器、replay 及随机数状态；GC 仅清理已无 checkpoint 引用的本轮分配 replay。提供无恢复数据的 review.tar.gz，只打包指标和初始/最终部署图。

验证覆盖：固定相同场景时两版 keep 原始一阶反馈一致；无候选点也持续更新 keep；神经网络仅替换正档位收益，且无一阶输入；候选不重复解码；网络冻结时参数不变；700 后自动切换；online 学习、标签预算与恢复；原校准路径定向兼容；恢复状态和小规模连续运行一致。
