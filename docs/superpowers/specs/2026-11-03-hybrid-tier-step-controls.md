# 正档位独立步幅与 checkpoint 分叉

用户批准三项：保留/正档位独立限幅、同一 checkpoint 分叉、记录原始与执行更新量，并询问不限幅是否必要。本轮独立入口支持正档位上限默认 1.0 和显式不限幅；q0 完整沿用源 checkpoint 的上限、反馈、历史和学习率。沿用源混合版的空间输入与冻结收益网络，不改变评估器。

## 行为

- 仅接受 dense_keep_neural_tiers_v1、冻结正档位网络的源分配 checkpoint。接受管线根目录、allocation 目录、state.pt 或一次固定快照目录。
- 先只读复制原子保存的 state.pt 与紧凑收益网络，校验身份，记录 SHA256。snapshot-only 不加载 CUDA、不训练；多个新实验使用这一快照实现相同起点。
- 新目录恢复表、全部历史、纠偏、候选覆盖、相机调度与随机状态。训练总目标默认沿用源 2000 步，保留全局步号，只运行剩余步骤。允许显式指定更大的 target-step。
- 分叉只重置本轮结果选择记录与初始对照图，不重置学习历史。源待执行 control/calibration 按顺序执行。fork_initial 评估不刷新通信代理，不改变下一步训练状态；评估使用已有配对 RNG。
- 独立正档位限幅表保留原 q0 计算逐位一致。正档位支持 1.0 默认、0.25 同上限控制、显式 unbounded。对数值溢出仍报错，原 -700 数值支持下限保留。
- 日志记录候选数、原始/实际两两最大 log-odds 步幅均值与分位数、步幅保留比例、触顶比例、候选 trust 和偏好概率变化。原字段保持可读。
- 完成后测末步、选中、全 q2/q3，生成紧凑 review.tar.gz；checkpoint/源快照不入结果包。默认不重复预训练，不修改原进程与目录。

## 验证

独立上限不影响 q0；0.25 与旧表逐位一致；不限幅与未限幅镜像一致；空候选与极小/大成本日志有限；相同快照三路起点相同；0.25 分叉后训练状态匹配原继续训练；断点恢复一致；源文件 hash 保持；快照无需 CUDA；原混合入口兼容。仅定向验证后提交推送。
