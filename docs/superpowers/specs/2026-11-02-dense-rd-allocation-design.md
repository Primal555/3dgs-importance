# 连续掩码 RD 分配恢复实验

用户已批准恢复完整 A 路线，收益网络留作后续研究。本实验新增独立入口，保持现有实验文件不变。

## 依据与结构

以历史提交 `3dc7df8`、`0e4e411`、`c495a21` 为依据，复用现存 `GaussianTierMask`、`local_mask_step` 及 successive 编解码器的 ST 前缀接口。输入为已完成的 successive 多场景训练目录，默认使用 Mip-NeRF 360 续训后的编解码器。四个编解码模块全部冻结，逐点学习保留概率与条件正档位概率。初始化保留概率 0.99，三个正档位等概率；每轮单次硬 Gumbel 采样，所有原始行均进入图像反馈与资源期望梯度路径。不可见点的图像梯度允许为零。部署沿用固定种子的十次采样规则。

实际前向使用硬 mixed 档位及真实 AWGN。正档位反向沿用整块正档位候选构成的局部 ST 近似；关闭点以零存在门控的反事实属性获得保留梯度。该恢复实验保留这两项历史近似，不宣称单点有限差分等价。

## 统一目标

`L = (MSE + lambda_s * (1 - SSIM)) / D_ref + beta * C / C_ref`。

`D_ref`、`C_ref` 取全 q3 在固定校准视角、固定信道试验种子下的参考值。结构项初始占参考失真的 20%，标定后固定。默认 beta=0.1。训练资源项对全部点的单次采样期望求导；XYZ 使用本轮实测压缩开销折算的每保留点局部代理，元数据及块尺度开销作为实测常量。校准与测试均计完整实际部署开销，包含属性、可靠 XYZ、元数据及 binary16 块尺度。可靠链路 bit/use 沿用源实验记录。

## 收尾与验证

最多 2000 步；最少 500 步；每 100 步在 4 个独立校准视角、4 次固定噪声试验下测部署 RD。相对历史有效改进不足 0.1%，连续 3 次后学习率减半，最多降至初始的 1/8。到达下限后连续 3 次停滞，且这段时间部署档位相对起点变化不超过 0.5%、实测开销范围不超过 0.2%，才提前结束。固定 beta，训练更新持续执行。校准用于调度与最低 RD 记录，真实测试相机仅用于初始、末步、最低 RD、全 q2、全 q3 报告。

报告末步与最低校准 RD 对应结果，目标仍为达到全 q2 画质且开销更低。未达标直接记录结果。默认 Adam：保留分支 0.01，档位分支 0.001，eps=1e-15。

## 效率、保存与恢复

复用每步语义特征、实际解码、q0 反事实结果，使用 replay 限制反向显存；成本计量复用现有坐标压缩缓存。输出仅保存一份最新恢复状态，包含表、Adam、RNG、视角游标、调度状态及最低 RD 概率表，引用源编解码器，无重复权重、replay 池或逐步场景副本。只保存初始与最终两组部署图，其余端点保存指标及档位数组。提供不含 checkpoint 的 review 压缩包。

恢复必须匹配源指纹、场景、训练配置；允许改变设备与保存/分析频率等执行参数。恢复截断超出 checkpoint 的日志。原子 checkpoint 支持进程正常信号中断后的重启；硬杀从最近保存点重放。
