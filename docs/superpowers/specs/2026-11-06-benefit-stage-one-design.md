# 收益网络第一阶段离线对照

用户批准先实现不运行完整分配的第一阶段，并改进指标打印。

读取当前宽网络实验的一个原子检查点及其完整历史回放，固定源状态。原组使用 CorrectionLearner 原损失，修复组保持网络结构与输入，单独拟合正档位差值的两个分量 RMS 和 RD 差值 RMS。尺度仅使用本次选定训练记录，固定后不再变化。

修复组以 q1/q2/q3 三对数值回归和连续 Bernoulli KL 方向监督为主；保留相对 q0 的共同价值辅助回归，默认权重 0.25。方向项权重沿用源设置，取消正档位的 2% 硬忽略区。所有尺度和权重写入 settings.json。原组完全沿用已有数值损失。

两组来自相同网络权重、相同归一化和输出尺度；均使用新 AdamW、源学习率和权重衰减、相同批次与 dropout 随机数。默认选取 4096 条固定训练回放，均匀抽样；训练源重要性权重在两组相同。输入只读，回放磁盘数据不复制或更新。保留有界 LRU 读取缓存。

默认仅进行 2000 次网络参数更新，每 250 次报告。独立固定验证集与已学过的近期训练回放分开打印。报告正档方向误判、RD MAE/RMSE、误判代价、三档选优代价与固定 q1/q2/q3、逐视角及窗口平均误差、相对 q0 共同误差和辅助四档选择。q0 指标明确为辅助，不执行删点。

完整快照来自检查点的一次读取，允许源训练继续推进。支持在更新 0 时只评估。此阶段不渲染、不加载 PLY/照片、不更新概率表、不修改在线训练入口。最终两组网络保留在服务器，review.tar.gz 仅包含小型指标与说明。

固定验证集描述早期留出上下文；近期训练回放不称为独立验证。当前策略的新独立标签留待下一阶段采集。
