## 本次仅新增诊断，没有更换解码器

`diagnose_position_path.py` 直接加载 checkpoint，在无噪声 q3 下执行真实 CPU 编解码。保持源 Morton 顺序和 256 点分块，前向 hook 提取自身 XYZ 头和 Context XYZ 修正。它不训练、不保存新权重、不渲染，并验证 checkpoint 文件哈希不变。

每块误差 `e_i = p_i - x_i` 拆为：

```
e_i = mean(e) + (e_i - mean(e))
sum ||e_i||² = N ||mean(e)||² + sum ||e_i - mean(e)||²
```

第一项是块内共同平移；第二项是块内相对位置误差。两者在平方误差意义下精确可加，不是用两个随意加权的训练 loss。

额外的“真值平移对齐”和“最佳仿射对齐”均使用源 XYZ，只为诊断误差形态，**不能放到接收端，不是可部署指标，也不能转换成未经测量的渲染 PSNR**。`self_only` 仅关闭最终 XYZ Context 加法项，编码器 Context 仍在；它不是重新训练的无 Context 模型。

## 全场景结果

最终统计覆盖 883,438 个 Gaussian、3,451 个块，不是抽样估计。CPU 全场景 RMSE=0.455905，与服务器记录 0.4559055 一致到浮点误差范围。

| XYZ 路径 | 原始 RMSE | 去除每块平均偏移后的 RMSE | 每块最佳仿射对齐后的 RMSE |
|---|---:|---:|---:|
| 完整解码 | 0.455905 | 0.336735 | 0.260822 |
| 去掉最终 XYZ Context 修正 | 1.306812 | 0.345757 | 0.261461 |

- 完整解码位置 SSE：块共同偏移占 **45.45%**，块内相对失真占 **54.55%**。
- 若只去除整个场景的同一个平移，最多解释 **5.62%** 的位置 SSE，不能把问题简化成整个场景平移错了。
- 关闭 XYZ Context 后误差很大，但两条路径去除各块均值后的 RMSE 差别较小：0.3458 → 0.3367。与当前联合训练模型中 Context 主要校正共同偏移的解释相符，不代表 Context 无用；两条自由加法路径可能共同适应/抵消，不能把单支输出视为独立训练能力。
- 即使使用真值把各块均值纠正，位置误差相对源最大轴半径的“各块中位数均值”仍约 **9.17 倍**（原始为16.15倍），不是修正中心就能恢复精细表面。
- 最佳块内仿射校正后仍有0.2608 RMSE，非单纯平移/统一尺度/线性变换问题。

留出块 pooled RMSE=2.174，而训练采样池 pooled RMSE=0.432。注意这不直接证明全局过拟合：固定留出块含第0块，单块RMSE=8.534，对 pooled SSE影响很大；世界尺度误差对离群块敏感，需同时看相对半径分布。训练采样池是可被采样的集合，不是所有点都访问等次数的证明。

详细文件位于实验目录 `position_path_full/summary.json` 和 `blocks.csv`。先行抽样结果在 `position_path_diagnosis/`，解释时以全场景结果为主。

## 下一轮设计方向（尚未实现）

优先考虑让接收端学习可区分的“块共同位置 + 逐点相对位置”，而不是两个可任意抵消的绝对位置加法头。共同位置从接收符号的块特征恢复，逐点相对位置保持点间差异，并通过零均值等结构约束明确分工；所有几何信息仍来自原32符号，不增加真实坐标/中心旁路。

Context 需要改善逐点相对细节，而不只是大幅补偿全局偏置。第一轮可保持原输出坐标规范和最终位置目标，不同时引入新的手工损失权重。必须同时验证共同偏移和局部失真，且继续以真实恢复图、PSNR/SSIM判断成功；不能只看中心误差或总loss下降。

这些是基于误差分解提出的假设，不是已证明的新架构效果，也不能据此把所有责任归结于解码器或承诺完美恢复。

## 复现诊断

```bash
python diagnose_position_path.py \
  --ply output/truck_mask_0005/point_cloud/iteration_30000/point_cloud.ply \
  --checkpoint output/truck_q3_noiseless_20260921_143154/codec_10000.pt \
  --out output/truck_q3_noiseless_20260921_143154/position_path_full_new \
  --max-blocks 0 --blocks-per-batch 8 --device cpu
```

必须用新输出目录，旧结果不覆盖。默认 `--max-blocks 128` 是均匀抽样再加全部已记录留出块；`0` 才是完整场景。脚本检查 PLY 点数/SH 阶数并记录其 SHA256；哈希用于审计，不冒充与训练时原始 PLY 内容的完整自动匹配。
