# 解码端接收特征 Point Transformer 实验

这是结构实验，不是已经证明更好的默认模型。原无噪声 q3 基线和已有结果均不覆盖。

## 原来已经有 Transformer，为什么还要改

原解码端的几何流与属性流都有固定序列窗口多头自注意力（含错位窗口），不是单层 MLP。但编码端已经使用源 XYZ 的 kNN 邻域、点对差异关系权重以及相对位置值编码。两端建模点间关系的方法不同。

新选项 `--decoder-attention feature_point` 借鉴编码端的分组关系注意力，不直接复制需要真实 XYZ 的几何邻域：

```
接收符号 + 档位/SNR -> 原有逐点特征
  ├─ 自身输出路径（保留）
  └─ 特征相似度 kNN -> 分组关系注意力 -> 多尺度 Context -> 原有输出头
```

- 邻域：每个处理块内，对归一化接收特征计算余弦相似度，取最多 16 个邻居（包含自身）。几何流和属性流各自建立图，每层重算。q0 和填充点不参与。
- 注意力：由 `q_i-k_j + MLP(归一化特征差)` 产生每组权重；特征差同时进入被聚合的 value。保留 LayerNorm、残差连接和 FFN。
- 多尺度：细尺度两层，x4/x16 池化尺度各一层；几何/属性两流均替换。当前默认 hidden96、四组注意力。
- 不再向此分支叠加序列槽位的正弦编码，避免把槽位接近误当成接收特征相似。x4/x16 池化仍使用已有块内槽位，因此**整个网络不是任意置换不变模型**。
- 硬 kNN 索引选择不反传；选中的特征差、权重与 value 正常反传。邻居是特征相似点，不宣称它们已经是真实空间邻居。

接收端函数仍只接收符号、档位、SNR 和共享模型；不接收真实 XYZ、源邻域、源块中心或新元数据。预算仍为每个非零 q3 高斯 32 复符号，没有手工坐标旁路。

## 控制变量

编码器、特征统计、输出 logcov、位置头选项、损失、固定学习率 2e-4 和不裁剪设置不变。同一随机种子下，替换注意力发生在共享模块初始化之后，编码器与输出头权重保持一致；解码器注意力及其初始输出不同，这是被测试的改动。

分别对 `xyz_decoder=additive` 和 `block_center` 测试新注意力，每个都与相同位置头的旧窗口注意力比较。没有同时把其它失败的解码探针叠加进去。

配置默认仍为 `decoder_attention=window`，老 checkpoint/包的配置哈希不变。新 checkpoint 明确保存注意力类型；跨类型初始化会被拒绝，需随机初始化本实验。

## 成本和风险

默认配置模型参数由 1,698,615 增至 1,926,743（约 +13.4%）。邻域搜索在每个最多 256 点的块内，距离矩阵为 O(BN²)，聚合为 O(BNKH)，不会搜索整个场景。它不是零成本替换；CPU 用时不能直接推断 RTX 4090 的速度或显存。

主要风险是早期接收特征没有形成可靠邻域、相似外观混淆空间关系，以及后续噪声导致邻域变化。本轮先固定 q3/none，不把动态档位或噪声鲁棒性混入判断。

## 本地与可选服务器入口

本地匹配对照脚本支持：

```bash
python scripts/compare_xyz_decoders_local.py \
  --ply output/truck_mask_0005/point_cloud/iteration_30000/point_cloud.ply \
  --out output/decoder_point_local_new --steps 300 --seeds 42 43 \
  --modes additive block_center --decoder-attentions window feature_point
```

每 50 步保存固定块位置误差、共同/相对误差和 loss。其 `summarize()` 额外记录“相同位置头下，新旧注意力”的 MSE 比值。局部块 RMSE 不是渲染 PSNR。

实验入口 `scripts/test_decoder_point_q3.sh` 默认随机初始化、10000 步、一阶段、q3/none、additive 位置头。可显式设置 `XYZ_DECODER=block_center`；不自动改变已有脚本的默认模型。每 500 步保存 checkpoint，训练结束后在同一目录 `render_history/` 渲染历史图像和指标。

此入口仅表示功能可运行，不代表建议在尚无稳定本地收益时直接开始长训。

## 本轮实际结果（2026-09-21）

本地 CPU、真实 Truck 八个 256 点块（四个拟合/四个留出）、seed42/43、各 300 步；块索引和采样协议与上一轮完全相同。旧窗口对照复用 `output/xyz_decoder_matched_local_20260921` 中匹配协议的记录；新配置默认字段不改变旧模型行为，编码器/输出头同种子初始化一致。

下表是第 200/250/300 步 MSE 平均后开根号，世界单位，不是渲染 PSNR：

| 位置头 + 解码注意力 | seed42 拟合 | seed42 留出 | seed43 拟合 | seed43 留出 |
| --- | ---: | ---: | ---: | ---: |
| additive + 原窗口 | 2.471 | 9.802 | 2.355 | 10.963 |
| additive + 新特征图 | 3.213 | 9.349 | 2.801 | 11.498 |
| block_center + 原窗口 | 2.538 | 8.356 | 1.932 | 8.313 |
| block_center + 新特征图 | 2.835 | 8.180 | 2.615 | 8.100 |

尚无稳定总体收益，故不切换默认模型、不推荐直接长训。block_center 的留出相对 RMSE 在 seed42 从 1.727 降到 1.394，seed43 从 1.723 降到 1.660，但共同偏移仍约 8；此种位置头的中心预测只读取自身特征，新 Transformer 直接作用的是零均值 Context 细节支路，因此不能把共同位置无改善等同于所有 Transformer 位置解码设计都无效。

额外只读诊断：对 seed42/additive 的 300 步模型，第一层几何解码注意力的 k16 邻居与源归一化 XYZ 的 k16 邻居比较（排除自身），平均重合率为拟合 19.58%、留出 14.99%。源 XYZ 只在此诊断中作参照，绝未输入接收端。特征图不是可靠几何图；但这项重合率也不能单独证明它导致性能下降，因为有用的特征关系不必完全等于几何邻居。
