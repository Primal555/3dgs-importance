# 第一阶段：固定编解码器的条件熵选档

## 实验问题

在同一份输入 PLY、全部输入点保留、同一编解码器下，检验 latent 的统计信息量能否指导 8／24／48 个复符号的选择。最终比较完整交付的源渲染／照片 PSNR、SSIM、LPIPS、实际通信成本和 RD。

MA-NTSCC 的256维是架构超参数；论文 V-A1 使用256维、5个通道组，未给出256为理论最优维数的推导。当前48维维持不变。未来改变 latent 维数需要重新训练语义读出、语义解码输入、信道映射和相关修复模块；扩大档位集需要对应的编解码器权重。

参考：https://arxiv.org/html/2505.12740v1 ，III-B／V-A1。

## 模型与梯度

- 读取源 checkpoint 的48维和0／8／24／48配置。所有原始输入行保留，填充位置关闭。输入 PLY 本身可能已经过 MaskGaussian 剪枝。
- 原始256点块及行号保持不变，先语义编码一次，缓存供熵训练复用的 CPU float32 latent。缓存按源行号排列，另存原始块号；源权重、属性统计、场景指纹均固定。校准与测试调用现有完整编解码评估入口。
- 以完整编码块划分80%训练、20%验证，随机种子固定。标准化均值／标准差只用训练块，标准差下限1e-6。
- 概率支路使用固定宽度0.25的标准化区间。将 latent 映射到相应区间中心，仅用于统计评分，实际信道仍接收原始连续 latent。
- 条件密度分3组，每组16维。第一组学习全局逐通道3分量 logistic mixture；后两组分别读取前16／32维的区间中心，以两层128宽 GELU 网络输出当前16维的混合权重、位置和尺度。
- 当前组及后续组不作为本组分布预测输入。组内条件独立，组间显式相关。通道分组与传输档位无对应关系。
- 用解析的 logistic 区间对数概率和 logsumexp，避免饱和 CDF 相减及硬概率截断造成的零梯度。密度计算使用 float64，网络参数为 float32；尺度为softplus＋0.01。
- 优化目标为每维平均负对数似然，报告 bits／高斯。只更新熵模型，编解码器无梯度；评分／硬选档／渲染校准均无梯度。
- 默认20个完整训练遍历、batch4096、Adam学习率1e-3余弦下降至1e-4。每轮随机打乱且完整覆盖训练样本；报告裁剪前梯度范数和触发比例。使用末轮模型。

## 选档与真实计费

信息分数为48个通道区间自信息量之和。使用 k=Q(eta*I)，Q在源checkpoint的正档位中向上取整，超过上界取最高档。统计bit仅用于分配打分。

默认从训练来源场景的全部信息分数生成9个对数间隔eta，以5%／95%分位数限定搜索范围；也允许显式给出eta。此步骤不读取图像误差。相同档位图按完整源行哈希去重。

在4个训练来源校准视角、4次配对噪声试验下，用真实混合档位重新编码并渲染。逐块尺度重新计算，不拼接固定全档位恢复结果。复用现有 ExactDeploymentCost，计入属性符号、坐标、尺度和完整元数据。计费使用源实验显式保存的可靠路径净bit/use假设。

RD沿用原目标：D=(MSE+lambda_s*S)，J=D/D_ref+beta*C/C_ref。默认beta0.1、结构份额0.2，lambda_s和D_ref由相同全q3校准参考一次确定；C_ref为真实全q3成本。所有映射共享相同参考。按校准RD选择eta；最终在原测试视角比较选中图与全q1／q2／q3。测试结果不参与选择。

第一阶段固定q0，删点反馈、十次部署规则与在线收益网络均不参与本实验。新增模块不改变既有入口。

## 保存与恢复

- 保存 plan、training、逐轮NLL与梯度日志、校准候选、最终指标、分配分数统计、选中档位图、最终熵模型和 latest 优化器状态。
- 每轮原子保存checkpoint，恢复从完整轮次边界继续；校准／测试按身份匹配的已完成结果恢复。
- 大型latent缓存留服务器供恢复，review.tar.gz只收纳报告、计划、日志和选中图／q2的少量对照图，排除latent与优化器。
- 默认只保存选中图和全q2的2个均匀抽取测试视角；含档位可视化。图像对照及指标复用原评估器。

## 定向验证

1. 区间概率归一性、正常区间与直接CDF相减一致、远尾有限梯度、参数有限差分。
2. 条件因果性、训练统计与验证隔离、原始行号和填充位置处理。
3. 完整遍历、末轮选模、精确恢复；固定编解码器权重和梯度边界。
4. 硬档位映射单调性、只产生支持档位、原行顺序成本一致、校准去重与测试隔离。
5. CPU小场景入口及真实既有信道路径测试；CUDA渲染性能留服务器验证。

本地11项定向测试通过；独立审查发现的变长末批索引与首轮中断恢复问题已修复，并加入回归用例。

## 运行与检查

```bash
RUN="$PWD/output/successive_mip360_gpu1_20261023_142948/training"
GPU=3
OUT="$PWD/output/truck_entropy_stage_one_gpu${GPU}_$(date +%Y%m%d_%H%M%S)"
CUDA_VISIBLE_DEVICES="$GPU" RESUME=0 nohup bash scripts/test_entropy_stage_one.sh \
  "$RUN" truck "$OUT" >"${OUT}.log" 2>&1 &
printf '%s\n' "$!" >"${OUT}.pid"
tail -n 40 -F "${OUT}.log"
```

第一段显示每轮训练／验证 bits/G、梯度范数、裁剪比例、完整访问次数及时间；随后打印每个 eta 的档位分布、实测成本和校准 RD。默认每轮训练约80%的源高斯，完整遍历20轮。它与历史实验的700个采样窗口含义不同。

结束后查看 `complete.json`、`comparison/summary.json` 和 `metrics/entropy_training.jsonl`。检查包为 `review.tar.gz`。中断后使用相同 RUN、OUT 和超参数，设置 `RESUME=1`；恢复到最近完整轮次，并复用已完成的校准和测试记录。

`information_summary.json` 的分数单位为统计 bit/G。通信结果统一读取 `cost.total_channel_uses`，其单位为复信道使用次数。熵模型仅在发送端生成已计费的档位元数据，接收端仍只依赖原编解码器与实际收到的数据。
