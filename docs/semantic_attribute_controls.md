# 语义属性恢复对照实验

本实验比较连续语义表示的恢复失真。输入已有源 PLY，全部点保留，源属性固定；语义编码器和解码器从随机权重训练。源实验仅提供场景路径、相机划分及空间配置，不加载源模型权重。

## 四组配置

| 组别 | latent 实数维度 | 几何专用 | 基础色专用 | 高阶色专用 | 共享 |
| --- | ---: | ---: | ---: | ---: | ---: |
| shared128 | 128 | — | — | — | 128 |
| shared256 | 256 | — | — | — | 256 |
| split128 | 128 | 16 | 16 | 64 | 32 |
| split256 | 256 | 32 | 32 | 128 | 64 |

语义输入为 XYZ 和56维属性。几何组含透明度1、尺度3、四元数4；基础颜色为零阶 SH 3；高阶颜色为 SH 45。编码端分别嵌入 XYZ、透明度、尺度、旋转、基础颜色、高阶颜色，经过共享融合与空间上下文后映射到连续 latent。四组均使用这六类输入嵌入。分流组的各段 latent 从同一编码主干投影得到，解码分支只访问本组专用 latent、共享 latent、16 bit交付 XYZ 和有效点掩码。各分支拥有独立上下文与输出头。

所有组主干宽度256，空间超参数相同。分流组有三条解码分支，参数量和计算量较大，因此此对照衡量“属性分流结构”的整体收益；每组实际参数量写入 architecture.json。128、256维属于扩展表示，本实验不测量压缩率或复信道使用次数。48维沿用历史结果，不新增训练组；历史多阶段训练结果与本轮随机初始化结果分别标注。

参考：MesonGS，ECCV 2024，按属性区分 RAHT、尺度量化和高阶 SH 向量量化；FCGS，ICLR 2025，区分几何直接量化与颜色自编码路径。本实验借鉴属性分流思想，采用可接入后续信道编码的连续学习表示，没有复现其熵编码或码本。

- https://arxiv.org/html/2410.08017v3

## 数据、视角和目标

默认 Truck、Playroom 轮换训练，DrJohnson 为本轮留出场景。训练 PLY 使用 RUN/training.json 中的原路径；DrJohnson 使用 configs/multiscene_tandt_db.json 指定的 PLY，与既往留出评估保持来源一致。可通过显式 manifest 覆盖迁移后的路径，训练源 PLY 指纹及相机身份仍须匹配。训练统计只由两个训练场景拟合，每场景权重相等，四组共用。

每步选取32个不重复训练视角，以每场景、每阶段独立的打乱循环覆盖训练相机池。验证池扩展到32个：保留源实验验证相机，新增部分从源训练池移出。本轮从随机权重开始，新增验证相机不参与本轮训练。原测试视角保持不变，最多32个，Playroom原有29个时保留29个；测试视角不用于梯度、归一化、选模或停止判断。源 PLY 自身由此前的场景重建获得，本实验的视角隔离针对语义编解码器训练。

默认每组总计4000次 Adam 更新，两个场景交替：

1. 属性阶段3000步，每场景1500步。每步读取16个256点空间块，32个训练相机提供方向颜色监督，不执行图像渲染。固定计数驱动的打乱块循环使四组使用相同样本。
2. 渲染阶段1000步，每场景500步。每步恢复完整场景，同一场景的32视角损失取平均后执行一次更新。视角梯度流式累计，语义编解码器只进行一次完整前向和一次分批 VJP 重算。

学习率分别为1e-4、1e-5，阶段切换重新创建 Adam。每250步验证一次，每100步保存最新状态。bootstrap_end 和 final 是固定终点，验证曲线用于观察平台和退化。各组从同一随机种子出发；不同维度网络形状不同，不声称整个网络初始参数相同。

属性损失为五项独立损失归一化后的等权平均：

- 激活后透明度 MSE，除以训练透明度方差。
- 对数协方差矩阵 MSE，除以训练对数协方差的平均方差。矩阵写作 R diag(2 log s) Rᵀ，规避特征分解反传；四元数符号和等价主轴表示不造成虚假差异。
- 基础 SH 归一化系数 MSE。
- 高阶 SH 归一化系数 MSE。
- 32个训练方向的未裁剪 RGB MSE，除以根据训练 SH 方差计算的球面平均颜色方差。

透明度、形状、方向颜色尺度下限均为1e-4，属性标准差下限沿用0.01；它们由训练数据一次拟合并固定，不使用预测误差或验证集定标。数值写入 attribute_statistics.json。

渲染阶段使用源 PLY RGB MSE＋(1/3)×(1−SSIM)＋0.01×属性损失。MSE 使用未裁剪 RGB，SSIM 使用 [0,1] RGB，与现有实现一致。LPIPS 为评估用 VGG v0.1。权重是本轮固定实验配置，四组相同；没有自动动态权重或梯度限幅。

## 失真与容量观察

评估每张相机分别计算指标，再对相机取平均，测试只在属性阶段终点与最终终点执行。输出以下对照：

- source：原始 XYZ＋原始属性。
- xyz_only：16 bit交付 XYZ＋原始属性。
- semantic：16 bit交付 XYZ＋语义恢复属性。分别报告相对 source、真实照片及 xyz_only 的指标。
- 最终额外恢复几何、基础颜色、高阶颜色三个属性组，逐组替换为源属性进行渲染，定位主要损伤来源；替换收益不能相加当作误差分解。

记录每类属性平均误差、95%及99%分位；固定空间块上记录 latent 方差、特征值、有效秩、近常量维度比例。使用0.01、0.05倍各维标准差扰动观察属性敏感性，扰动仅用于诊断，不进入训练或通信成本。共享组整体扰动；分流组逐个 latent 分区扰动。输出敏感性和容量图，跨属性单位不同，应在同一列比较影响。

共享编码融合层的各项损失梯度余弦在两个固定诊断块上测量，诊断不修改优化器或梯度状态。有效秩和扰动结果用于解释表示使用情况，不等价于信道抗噪性能。

## 效率、检查点与输出

源渲染按相机缓存到 CPU，四组串行时复用；位置量化参考及其指标也复用。三个解码分支共享单次调用内的空间邻域几何计算，学习特征与梯度各自计算。完整场景解码按批次执行，padding 不计入属性损失；渲染辅助损失按有效点数加权。

每组保留 latest.pt、bootstrap_end.pt、final.pt，包含网络、Adam、随机状态、视角循环、阶段进度和数据身份。中断后必须使用相同设置恢复。review.tar.gz 只包含配置、日志、指标、少量同视角图片及图表，不含检查点或全场景属性缓存。恢复训练需要另外保存检查点与原始数据。

### 启动

```bash
conda activate maskgs
git pull --ff-only origin experiment/feedforward-student
GPU=3
RUN="$PWD/output/successive_mip360_gpu1_20261023_142948/training"
OUT="$PWD/output/semantic_attribute_controls_gpu${GPU}_$(date +%Y%m%d_%H%M%S)"
CUDA_VISIBLE_DEVICES="$GPU" RESUME=0 nohup bash scripts/test_semantic_attribute_controls.sh \
  "$RUN" "$OUT" >"${OUT}.log" 2>&1 &
printf '%s\n' "$!" >"${OUT}.pid"
tail -n 40 -F "${OUT}.log"
```

默认顺序运行四组，合计16000次更新。可以在不同 OUT 下用 `--arms shared128`、`--arms shared256`、`--arms split128`、`--arms split256` 分别启动；数据顺序和视角轮换保持一致。`--blocks-per-batch` 控制显存，四组对照应使用同一值。断点续训设置 `RESUME=1`，保留相同 RUN、OUT 和其他选项。
