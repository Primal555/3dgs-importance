# 全接收前缀的末端空间协同：独立实验

## 本轮问题与边界

验证低档点能否利用高档邻居**实际已收到**的增强信息，更准确恢复自身 latent y。
不是再次引入残差概念，也不改变符号预算：新方案将原来的三个阶段内去噪支路，替换为逐点解码完成后的一次末端残差修正。
已有 `test_channel_spatial_truck.sh` 和旧检查点行为保持不变。

发送仍然是同一个完整前缀源模型，默认 q1/q2/q3 为 8/24/48 个复符号。
XYZ 仍走原有可靠 16bit 量化、差分压缩路径。没有额外参考信号、坐标预测或反馈链路。
原语义编解码器、信道编码器和逐点信道解码器全部冻结，只训练新的接收端残差支路。
目标仍为 y 的 MSE，不做渲染反向更新，不训练档位分配器。

## 三个同源实验组

| 组名 | 新残差位置 | 邻居可用信息 |
| --- | --- | --- |
| `stage_spatial10` | 三个恢复阶段内各一次 | 当前阶段前缀及当前中间恢复；只在 q≥当前阶段点中聚合 |
| `final_pointwise10` | 全部逐点恢复结束后一次 | 只看自身实际收到的前缀、接收掩码和最终恢复 |
| `final_spatial10` | 全部逐点恢复结束后一次 | 自身和邻居实际收到的全部前缀、掩码、最终恢复 |

末端两组使用相同网络参数量、相同非零隐藏初始化、相同零初始化残差输出，区别仅在邻域是否跨点。
逐点控制并非严格等有效容量/FLOPs；其注意力选择退化为只看自己。
阶段内参考有三个支路，末端两组各一个，**阶段内与末端不是严格参数匹配的因果对照**。
不能把阶段内与末端的任何差异全部归因于“允许读取高档信息”；主要先看末端空间组相对末端逐点组的收益。

三组从同一完整前缀、无新增去噪器的检查点出发，初始函数相同。
均默认新增 2000 次真实 optimizer 更新，10 dB AWGN、1e-4 学习率，新支路使用新的 Adam。
源模型原 Adam 不用于新支路，不是续训旧网络。训练点批次、q1/q2/q3/mixed 顺序、随机流配对。
三组顺序运行在一张 GPU，共 6000 次新增更新，不是每组只跑约 667 步。

## 接收端数据边界

最终输出：`逐点信道恢复 y_hat + 接收端协同修正量`。
邻域基于已交付 XYZ，按世界空间欧氏距离选取同一个原 Morton 块内最多 16 点（包含自身）；隐藏宽度 64。
q1 点可以利用 q3 邻居的增强符号，也可以利用邻居的最终恢复 y_hat。
q1 **自身没有发送的槽位仍不可读取**，q0/padding 不当作查询或邻居，不跨局部块/codec batch。
只使用带噪接收符号和恢复特征，不向接收端提供正确 y 或源属性。

`decode_stages()` 继续返回原有独立可用的逐层恢复；末端协同由 `forward()` 在其后执行。
因此收到基础层时仍可恢复；邻居增强层到达后，可重新计算协同输出，让低档点也获益。
本实验不模拟逐包到达、丢包或动态修改档位，不证明部署时依赖高档邻居一定稳健。

## 启动与结果

```bash
CUDA_VISIBLE_DEVICES=3 bash scripts/test_channel_cooperative_truck.sh \
  output/truck_full_prefix_gpu3_20261015_094337 NEW_OUT
```

源目录可以是完整前缀实验根目录，也可以直接是其中的 `full_prefix10`。
只读源目录；新输出不得覆盖或包含源目录。中断恢复用同样参数加 `--resume-suite`。
每 500 步保存数值验证和 latest 检查点；仅最初和最终保存 clean/q1/q2/q3/mixed 渲染图。
各组日志、检查点、诊断和横向图表均放在 NEW_OUT 内。

重点查看：

- `comparison/summary.json`：三组 q1/q2/q3/mixed 的照片/原 PLY 指标、末端空间相对末端逐点增益及相对阶段内参考增益。
- `comparison/psnr_curves.png`：三组相同视角、相同噪声下的 PSNR 曲线。
- `comparison/latent_errors.png`：无噪声 NMSE、有限次噪声均值误差、噪声方差。
- 各组 `diagnostics/{initial,final}/latent_errors.json` 的 `mixed.by_tier`：固定随机混合档位下，分别统计目标为 q1/q2/q3 的 y 误差。该分组比仅看 uniform q1 更适合判断低档点有没有从高档邻居获益。

mixed 为固定随机正档位图，**不是已学习分配后的部署图**；特征诊断的固定 mixed 图与渲染验证的固定 mixed 图是两个独立、明确配对的随机图。
诊断先解码完整原分组，再对目标点抽样，不重新拼组；三组及前后端点采用相同样本和噪声。
所有组符号 payload 相同；共享模型参数和配置会变化，不能宣称模型存储/配置元数据字节完全相同。

这是能力验证，不保证层层画质单调，不保证零偏色，也未验证多场景泛化或高档邻居丢失的鲁棒性。
