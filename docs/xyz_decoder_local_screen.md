# 先在本地筛选位置解码升级（2026-09-21）

结论：撤回“把上一版直接交给服务器长训”的建议。本轮新增三个明确标记的实验解码选项和可复现 CPU 对照脚本，但**没有一个修正版获得足够稳定的优势，因此不替换现有默认结构，也不新增推荐的服务器启动脚本**。不能把实现完成等同于质量修复完成。

## 原先结论为什么需要补查

原先只比较一个种子的 100 步，且两种结构的初始 XYZ 输出不同。该检查足以发现风险，不足以认定块中心分解必然降低最终拟合能力。本轮使用相同数据、相同采样和观察方向序列、两个种子、300 步，观察每 50 步验证结果，不只挑最后一个点。

## 做了哪些改进尝试

- `residual_center`：完整保留旧 additive 位置路径，在自身/Context 池化特征上增加零初始化的块平移残差。初始输出和共享参数梯度与 additive 一致。目的是避免强制替换原位置函数导致退化。
- `symbol_skip`：完整保留 additive 路径，增加接收符号到 XYZ 的零初始化可学习线性读出。它不是直接交付 XYZ，而是缩短位置梯度传播路径。
- `context_center`：在上一版 block_center 基础上，让中心 MLP 同时读取自身与几何 Context 的池化特征。新增 Context 输入权重初始化为零，因此初始函数与 block_center 一致（浮点容差内）。仍保持逐点偏移/最终 Context 修正零均值。

三者均不增加信道符号，不接收源坐标/源中心，不改变编码器、logcov、原有一阶段损失或学习率，不使用梯度裁剪。它们仅是**本地实验探针**，不是已证明有效的新默认。

## 同条件实验

完整原始 PLY 拟合输入统计，无旧 checkpoint 权重初始化；Morton 排序后取 `[40,440,840,1240,1640,2040,2440,2840]` 八个 256 点块，交替分成四个拟合块和四个留出块。

- seed=42/43；hidden96、depth2、q3、32 复符号、none 信道。
- Adam 2e-4 固定，300 步，每步随机选两个拟合块；每步四个随机观察方向，所有结构对应种子共享独立采样 RNG 序列。
- 每 50 步验证；下表是第 200、250、300 步 MSE 的平均值再开根号，不是最佳 checkpoint。
- 块数极少，检查的是局部训练表现；并非全场景、跨场景或渲染质量结论。

| 结构 | seed42 拟合 RMSE | seed42 留出 RMSE | seed43 拟合 RMSE | seed43 留出 RMSE |
| --- | ---: | ---: | ---: | ---: |
| 原 additive | 2.471 | 9.802 | 2.355 | 10.963 |
| 上一版 block_center | 2.538 | 8.356 | 1.932 | 8.313 |
| 残差中心 residual_center | 3.121 | 10.008 | 2.569 | 10.881 |
| 符号捷径 symbol_skip | 2.566 | 9.622 | 3.186 | 13.152 |
| Context 中心 context_center | 2.504 | 8.236 | 3.039 | 8.678 |

上一版的拟合大幅退化并没有在 300 步末段稳定复现；但也不能说它已全面胜出。新增三条路径均未稳定超越基线。工程筛选规则是：至少两个种子，每个种子的拟合和留出末段 MSE 都不高于 additive；这只是保守的本地筛选，不是统计显著性检验。没有候选通过；小幅差异可能是优化波动，不据此宣称结构不可行。

更有价值的是误差构成：block_center 的留出块相对 RMSE 在两个种子分别为 1.727、1.723，优于 additive 的 3.632、6.308；但共同偏移仍为 8.176、8.132。拟合块共同偏移也比 additive 高。**局部排列和共同位置必须分开看；只扩展中心输入或追加捷径还没有解决共同位置的学习。**

额外只读检查：冻结旧 10000 步 codec，在四个拟合块的接收符号上拟合线性 XYZ 读出。拟合 RMSE 0.778→0.519，但留出 0.289→1.318；这说明拟合提升不等于可靠读出，不能据此断言编码端已充分编码位置或解码器是唯一瓶颈。这些留出块只对读出器留出，并非旧 codec 的未见场景。

## 代码、记录与复现

`scripts/compare_xyz_decoders_local.py` 保存协议、每步 loss/梯度范数、每 50 步分解指标和各次 checkpoint。各方案都是随机权重，使用普通反向传播；没有场景渲染。`summarize()` 拒绝不完整或协议不一致的比较，保存末段比较 JSON 和图。

本次本地输出目录：

- `output/xyz_decoder_matched_local_20260921`：additive/block_center/residual_center。
- `output/xyz_symbol_skip_local_20260921`：symbol_skip。
- `output/xyz_context_center_local_20260921`：context_center。
- 完整合并结果放在第一目录的 `comparison_final/`。

复现时换一个新的输出目录：

```bash
python scripts/compare_xyz_decoders_local.py \
  --ply output/truck_mask_0005/point_cloud/iteration_30000/point_cloud.ply \
  --out output/xyz_decoder_local_new \
  --steps 300 --seeds 42 43 \
  --modes additive block_center residual_center symbol_skip context_center
```

此脚本是 CPU 定位用，不是新一轮服务器正式训练建议。下一步优先扩大本地块覆盖、检查中心分支实际更新和拟合/留出分布差异；在共同位置和稳定性改善前，不恢复噪声、动态档位或场景渲染训练来掩盖问题。

代码验证：完整回归 189 项，4 项跳过，其余通过。新增测试覆盖相同初始化函数、共享梯度、新增路径可训练、无坐标旁路、q0/填充、直接反向与 replay 一致、CLI/保存加载/诊断、匹配实验脚本以及不完整/失败种子的筛选拒绝。CPU 测试中的模拟 renderer 不用于证明真实渲染质量。
