# 连续证据与结构失真分配实验

入口 `gaussian_jscc.structured_evidence_allocation` 已升级为 v2，检查点 family 为 `calibrated_structured_allocation_v2`。复用同一冻结教师，从新的概率表开始；不重训编解码器、不接联合微调。v1 分配历史不能作为 v2 的 exact resume。

## 默认实验

- Truck、10 dB、原教师的 0/8/24/48 复符号预算，可靠 XYZ16 与 binary16 分段尺度。
- 2000 次更新，每次 4 个训练视角；校准视角与训练窗口互斥，测试视角不参与更新或选模。
- 单次采样训练、十次规则部署保持不变。beta 显式传入，建议首轮沿用 0.1。
- `D=M+lambda_s*(1-SSIM)`；`L=D/D_ref+beta*C/C_ref`。M 为未截断 RGB MSE，SSIM 使用 [0,1] RGB、11×11 高斯窗口、sigma=1.5、零填充。PSNR/SSIM/LPIPS仍分别记录。

## 固定权重与参照

冻结教师的全 q3、固定校准视角、默认 4 次配对 AWGN 试验得到 M_ref 和 S_ref。默认 `--structure-share 0.2`：

```
lambda_s = 0.2/(1-0.2) * M_ref/S_ref
D_ref = M_ref + lambda_s*S_ref
C_ref = 全 q3 实际通信成本
```

20% 是可调的参考贡献份额，不是直接乘在 SSIM 上的系数。`--lambda-s VALUE` 优先于份额自动换算。参考量接近零时自动标定报错，需明确指定权重。`--distortion mse` 是纯 MSE 对照，不计算结构梯度或结构精确差分。SSIM内部使用float64局部图，与旧float32报告指标有舍入差异；额外保存 `source_objective_mse`，旧 `source_mse` 指标语义不变。

## 近似历史与独立精确纠偏

MSE/结构两分量分别保存衰减均值、二阶矩、有效权重、观测次数及最后更新时间。历史分量以固定 D_ref 归一化；通信差价每步重新计算，不在历史里平均。默认半衰期1000步，概率分布漂移仅触发刷新提示，不清空整块历史。

保留反馈按 q1/q2/q3 存三个槽，记录对应正档位相对关闭的代价。三个槽有效权重均≥0.5且不超过一个半衰期才按当前条件概率混合；否则使用本步采样档位刚更新的历史值，缺测槽不补零。所有q0都保留基础门梯度。

近似主历史每步累计一份近似观察。精确评价另存 `delta_exact-delta_proxy`，按“原始点＋当前档位＋替代档位”保存稀疏记录；保留／删除再区分当前存在状态及对应正档位。普通近似观察不能增加或稀释纠偏历史的权重。当前精确动作直接采用本步真实差值，其他动作由近似均值加匹配纠偏得到。未检查的动作没有精确记录。

查询纠偏时，按距上次精确检查的步数和块内实际 q0–q3 分布的 TV 距离平滑衰减；半衰期沿用1000步，上下文尺度沿用0.1。更新纠偏历史时也按上述新鲜度衰减旧权重。块分布用于概括邻域变化。

## 有效评价量与概率更新

近似历史和纠偏分别保存权重平方和。Kish有效样本量为 `sum(w)^2/sum(w^2)`；再取其与“已见训练视角数／每窗口视角数”的较小值。视角集合用CPU位集保存，重复使用同一组视角不能持续提高有效样本数。均值标准误使用 `std/sqrt(N_eff)`，并叠加纠偏不确定性；单次精确检查保留跨视角不确定性。

置信度按完整RD动作差价与其标准误的比例计算，包含确定的通信差价，取值0.1～1。q0使用实际参与条件混合的历史及相同条件权重计算标准误。最大log-odds步长仍为0.25，无档位配额或强制概率锐化。原始观察次数、有效样本数和置信度分别记录。

## 决策导向精确反馈

每步默认32个独立反事实：优先24个正档位、8个保留/关闭，不足可互借。各分支轮换三类优先级：RD边界/大概率移动、历史波动/精确误差/上下文刷新、最低精确覆盖，不能整除3的余数按训练步轮换。覆盖按“点＋具体替代动作”的精确次数安排，避免某点反复检查同一档位；保留检查独立使用对应正档位槽的精确次数。每个反事实单独改变一点并重解码完整受影响块，同相机、配对噪声，关闭/打开时重建语义上下文。

MSE使用逐像素 `2*r*delta+delta²`；结构使用float64局部SSIM图差分，复用基准图和目标统计。检查的是混合失真加通信差价后的决策方向。检查记录同时保存原始一阶预测和历史纠偏后的预测，以及各自方向一致性、绝对误差和错误决策代价。校准后预测在吸收本次精确结果前计算，可用于观察纠偏的后续收益。高损失的纠偏失败进入已有风险排序，抽检结果描述的是被选中的案例。

通信训练仍使用边际代理：可靠坐标平均保留成本、分段尺度实际开关变化/平均代理、档位payload；不把压缩放进每个候选。控制与选模使用包含payload、坐标、档位元数据和尺度的真实包成本。可靠侧净2bit/use沿用既有假设，不能将模拟复符号换算为无条件文件MB。

## 输出和判断

初始、最终selected/latest保留部署图与档位图（相同端点复用）；中间只有数值，最终保存同教师全q2/q3数字对照。`comparison/structured_controls.csv` 对比真实成本、源PLY/照片指标、两分量和RD；`structured_evidence.json` 保存所选模型的历史、有效样本量、置信度、纠偏动作数和固定参考；`charts/structured_evidence.png` 展示分量、有效历史以及纠偏前后的抽检RD误判趋势。`loss.jsonl` 额外记录每步实际复用纠偏的动作数、校准前后误判损失。

优先检查有效历史、纠偏复用、校准前后的错误决策损失，以及同成本下PSNR/SSIM/LPIPS的变化。全q2的成本/画质关系作为阶段性参照。v2保持32次精确渲染预算，新增统计在CPU计算；Truck单步速度、峰值显存及实际画质在服务器测量。

历史、视角位集和稀疏纠偏保存在CPU，完整快照包含这些状态以支持一致恢复。下载图表分析时可只拉取 `metrics/`、`comparison/`、`charts/`、`evaluation/` 和 `deployment/`，将完整 `checkpoints/` 留在服务器供续训，避免重复下载大历史。
