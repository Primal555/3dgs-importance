# 独立颜色与属性监督：两个随机信道 8000 步实验

两组保留同一语义教师、网络结构、逐块功率归一化、可靠16bit XYZ、
8/24/48复符号和10dB AWGN。信道编码器与解码器从相同seed42随机权重开始，
Adam为空；绝不加载源信道权重。只训练信道两端，语义两端及属性标准化全程冻结。
8000步是每组总更新次数，不是每个任务8000步。没有联合渲染训练或档位分配。

## A：color

前三次更新使用现有 `y MSE + lambda * 局部黑白RGB响应MSE`，第四次仅用方向颜色MSE。
8000步包含6000次原目标更新和2000次颜色更新。

lambda默认明确沿用此前同随机初值的8000步实验中测得的
`0.10235305148738072`，不再次用四批次校准；可通过 `--response-weight` 显式修改。
它是工程控制值，不是已证实的最优权重。

颜色目标是 `c(D0(y_hat),d)` 与 `c(D0(y),d)` 的未截断RGB MSE，
不乘透明度，不乘形状。8个方向中4个来自源实验的**训练相机名单**、4个各向同性。
验证/测试相机不提供训练方向。颜色步骤不附加latent或联合响应损失。

## B：separated

每四次更新依次仅优化：latent MSE、形状足迹MSE、透明度MSE、方向颜色MSE。
各2000次，不把这四项相加，不使用lambda，也不反向原联合响应。
原联合响应仍作为每步诊断记录。

- latent：有效点全部y维度的MSE，目标y停止梯度。
- 形状：不同方向投影的峰值为1的Gaussian轮廓，在相同物理尺度、相同中心、
  相同采样位置比较。使用参考与预测支持域的并集，采样位置停止梯度，
  避免预测形状逃出参考采样范围。保留原有相对 `1e-5` 协方差数值正则。
  不把每个预测单独缩放到自己的标准尺寸，不比较有符号四元数数值，
  不包含XYZ、颜色、不透明度。
- 透明度：激活后的 `sigmoid(opacity)` MSE，不比较未激活logit，
  不包含颜色与尺寸。该目标不含场景遮挡，不能替代最终渲染评价。
- 颜色：与A相同。

所有属性参考都是冻结教师的clean输出，不是原PLY属性，也不是真实照片。
语义解码器对预测分支保持对输入的梯度；仅教师目标分支停止梯度。
完整原始Morton块先进入解码器，只在计算逐高斯损失时展开；排除padding。

## 对照边界与调度

每种任务都有独立q1/q2/q3/mixed轮换游标，从步数可精确重建。
A中每个档位收到1500次普通更新和500次颜色更新；
B中每个档位收到500次latent、500次形状、500次透明度和500次颜色更新。
两组每个档位共2000次，颜色频率相同。

频率本身就是目标权衡，不宣称消除了超参数。
B的latent专训只有2000次，而A有6000次包含latent的更新；
因此A/B比较的是两套完整监督策略，不是“只移除乘法”的严格单变量消融。
参数仍共享：某项损失只依赖一种属性，不意味着其更新不会影响其他属性。

## 输出和恢复

一个suite目录包含 `color/`、`separated/` 及两个 `.log`、`.pid`。
每组记录每步 `task`、`task_step`、布局、四类误差、方向RGB偏差、联合响应、
实际参与反向的项、信道更新量、语义零更新、梯度与峰值显存。
诊断项不参与当前任务反向传播，不将不同任务的总loss混作一条可比较曲线。
终端打印前四步以及每25步，避免每10步打印与四任务周期混叠、只看见两个任务。

每500步固定4验证视角记录指标、不存中间渲染图；起始和最终32测试视角、
4次配对噪声，记录clean/有限无噪声/10dB q1-q3及mixed的
原PLY与照片PSNR、SSIM、VGG LPIPS和颜色误差。只保留初始、最终代表渲染图。
mixed是随机正档位，不是学习分配的部署，不含q0。

每100步保存latest，准确恢复模型、Adam、RNG、任务计数与待完成的评估。
单组用原目录和完全相同参数加 `--resume`；不能通过改变variant恢复另一组。
并行脚本要求新suite目录，已启动的单组恢复请使用单组脚本。

```bash
GPU_COLOR=0 GPU_SEPARATED=1 nohup bash scripts/test_channel_supervision_parallel.sh \
  "$RUN" "$OUT" >"${OUT}.log" 2>&1 &
```

两变量可指向同卡，但未在本机验证双CUDA任务的合计峰值；建议先分卡。
LPIPS首次运行可能需要已有模型缓存或网络下载。两组初始化、数据/噪声种子相同，
但任务不同导致更新路径不同；单次训练种子不能证明统计显著性。

建议重点观察高档方向色差与无噪声偏色是否下降，LPIPS是否改善，
同时检查q1原有收益、结构细节以及透明度/形状是否退化，不只看PSNR。
