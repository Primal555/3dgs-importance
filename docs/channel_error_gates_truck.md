# 跨维误差、解码敏感性与逐特征门控：独立实验

## 目的与本轮范围

本轮实现三个环节：

1. 在已有逐维误差之外，记录完整的随机误差协方差、相关矩阵和均值误差二阶矩。
2. 冻结语义解码器，对完整原局部块内的目标点做特征扰动，判断误差方向对方向颜色的影响。
3. 冻结已训练好的仅自身修正底座，对比无输出门控和逐特征门控的邻居增量恢复。

不实施上一轮提到的双噪声训练/梯度累计，不增加符号预算，不做场景渲染反向更新。
**统计与敏感性本轮是诊断，不直接生成训练损失权重。**
发送端增强层重编码是有条件的后续步骤：需要先看到明确、可重复的高风险方向。
本代码输出候选方向及其证据，但不会凭任意阈值自动修改发送端，也不宣称已实现定向增强编码。

## 起点与两组对照

输入完成的 `pointwise10` 或 `final_pointwise10`，不能输入空间组或已有邻居增量组。
默认可以使用本轮已完成的：

`output/truck_channel_spatial_gpu3_20261015_102637/pointwise10`

也可以传入上述实验根目录，脚本自动找到其 `pointwise10`。
若传入末端协同实验根目录，则优先选择 `final_pointwise10`。同一次比较只使用同一个底座，不混合两者。

- `neighbor_plain10`：冻结底座输出，加一个独立末端邻居残差，门控固定为 1。
- `neighbor_gated10`：同样的底座、邻居模块和初始化，逐点、逐特征学习 sigmoid 门控。

新输出为 `冻结的仅自身恢复 + 门控 × 邻居修正量`。不是把自身底座替换掉，也不是重新训练旧支路。
两个新模块均具有相同的门控参数形状；固定门控组不使用这些参数，所以不是严格等有效容量对照。
输出层初始化为零，保证两组初始函数与源模型一致；学习门控初始为 0.5，而不是门控和修正同时为零导致梯度失效。
没有手工规定 q3 必须少修正。门控输入来自自身/邻居特征、实际接收前缀及掩码、SNR、已交付 XYZ。

邻域为原 Morton 块内部按世界距离选出的最多 16 点（包含自身），默认隐藏宽度 64。
高档邻居实际收到的全部增强符号和最终恢复特征可以帮助低档点。
q0/padding 不当作查询或邻居；没有发送的符号永远不可读；接收端不读取正确 y 或源属性。

每组默认 **2000 次新增更新**，固定 10 dB、1e-4，新邻居模块使用新 Adam。
源语义网络、信道编码器、原信道解码器和已训好的仅自身支路全部冻结。
目标仍为 y MSE，没有加入手工加权的颜色损失或额外方差惩罚。
同源 8000 步底座通常得到日志总步数 10000；这不是重新训练 10000 步。

## 误差矩阵的定义

对同一点的多次噪声误差 `e[t,i] = recovered_y[t,i] - teacher_y[i]`：

- `point_mean_error_second_moment`：每个点的有限次噪声均值误差外积，再对点平均，不减全局均值。
- `noise_covariance`：先减去各点自己的噪声均值，再计算跨维协方差；除数为噪声次数 T。
- `error_second_moment`：所有点/噪声误差的二阶矩。
- 三者满足 `error_second_moment = point_mean_error_second_moment + noise_covariance`，程序记录矩阵级分解残差。

这些字段保存在 `latent_errors.json` 的 `joint_error` 中。旧的 `point_mean_error_covariance` 仍保留，
但它是均值误差减去全局均值后的协方差，不等于随机噪声协方差。
有限 T 的点均值仍含估计噪声，T 分母的协方差不是无偏总体协方差；不能将两项当作已精确分离的总体因果来源。

## 固定解码器敏感性怎么测

默认固定种子选 4 个非空原局部块，每块一个目标点；块内其他点原样保留。
在正确 y 附近逐维做正负中心差分，测量完整块内所有保留点的 8 个随机方向 RGB，包含语义解码器的跨点影响。
RGB 使用未裁剪 SH 颜色，**不是整场景图像、alpha 合成或原始照片**。
参考为 `固定语义解码器(正确 y)`；它不能消除 clean 本身已有的偏色。

差分步长为该点特征 RMS 的 1%，RMS 下限 1e-3。再次用半步长测量，记录 Gram 相对差异；
该步长和探针数量是公开可调的工程设置，不是最优保证。
用 `G = J^T J / 输出元素数` 衡量方向敏感性，并在**同一个目标点**上估计各档位的噪声/均值误差。
不会把不同点的平均敏感性与平均协方差直接相乘。

对该点误差二阶矩 S 的特征方向 v，贡献为 `特征值 × v^T G v`，所有方向贡献之和为 `tr(G S)`。
也记录 `b^T G b` 和 `tr(G noise_covariance)`，以及实际非线性输出误差，用于检验局部近似是否可信。
R、G、B 分别保存敏感性矩阵、预测风险和实际颜色误差，并单独记录无噪声恢复误差，便于检查红色偏差与高档精度。
JSON 保存完整方向向量，CSV 保存能量、敏感性、风险和累计占比；不把某一维直接命名为颜色或形状。

局限：这是每个目标点的条件误差归因，**没有测量整场景所有点之间的噪声交叉协方差**，
不能将各目标点的局部风险简单相加，声称得到整场景渲染误差。
有限锚点、单随机种子也不构成独立留出泛化结论。

## 启动与观测

```bash
CUDA_VISIBLE_DEVICES=3 bash scripts/test_channel_error_gates_truck.sh \
  output/truck_channel_spatial_gpu3_20261015_102637 NEW_OUT
```

先在独立进程完成 `source_geometry` 诊断并退出，释放其 GPU 上下文，再顺序训练两个组，避免父进程占着显存。
不修改源目录；输出必须另建。中断后相同命令添加 `--resume-suite`，恢复新模块的 Adam、RNG 和真实更新进度。

主要文件：

- `source_geometry/error_geometry.json`：底座误差方向、完整颜色敏感性矩阵和近似稳定性。
- `source_geometry/direction_risks.csv`：按颜色影响排序的候选方向，不是自动资源分配规则。
- 两组 `diagnostics/{initial,final}/latent_errors.json`：全局抽样误差矩阵与 q1/q2/q3/mixed 误差。
- 两组 `diagnostics/final/geometry/`：相同锚点、方向、噪声的最终敏感性归因，和底座比较。
- `metrics/loss.jsonl` 中 `neighbor_gates_by_tier`：该训练批次更新前的门控均值、每维均值及点数；不是整场景部署门控。
- `comparison/summary.json`、`psnr_curves.png`：q1/q2/q3/mixed 的画质与门控对照。

每 500 次更新保存数值验证和 latest 检查点，只保留初始、最终渲染图。
所有新结果放在 NEW_OUT 内。源权重冻结、初始函数匹配和发送 payload 相同，不代表模型/配置元数据字节完全相同。
不得只用 y MSE 排名：同时检查 q3、无噪声精度、照片/原 PLY PSNR/SSIM、颜色偏差和局部细节。
